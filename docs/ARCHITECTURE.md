# Investment Manager 权威架构

## 1. 文档地位

本文只定义长期稳定的领域边界、决策链和系统不变量。具体资产、时域、特征、模型、Prompt、阈值和资金规模属于可替换的实验或 Release，不得反向塑造架构。当前实现与本文不一致的部分是迁移债务，不是第二套合法设计。

`AGENTS.md` 定义投资和工程原则；[`WORLD_COGNITION_DESIGN.md`](WORLD_COGNITION_DESIGN.md) 定义世界认知方法；[`SELF_EVOLUTION_DESIGN.md`](SELF_EVOLUTION_DESIGN.md) 定义现实结果如何改变未来行为和权限；[`DASHBOARD_DESIGN.md`](DASHBOARD_DESIGN.md) 定义只读投影。这些文档不得重复拥有同一业务裁决。

架构本身不产生盈利。它的作用是让每个投资判断都能被点时重建、现实执行、独立评价、限制权限并在失效后删除。

当前系统做中低频总资产管理，不参与依赖微秒或毫秒延迟优势的高频竞争：事件驱动认知与风险复核，Forecast 在预登记的定时槽或材料状态变化槽形成，资本只在出现新的可消费 Forecast、账户风险变化或目标自身失效时重算；行情、账户、保证金和硬风险仍由程序持续监控，不等待 AI。交易频率由收益持续性、成本、风险和 mandate 共同约束，不能把 AI 调用频率或诊断性 Forecast 频率直接变成交易频率。

长期业务对象是一个以结算货币计价的总投资组合，不是 BTC、某个策略或一组互不相干的交易。系统在生存约束内追求现实成本后的长期复利，并以跨市场环境的净增值、回撤和尾部损失共同衡量结果；“稳定盈利”不表示每个周期为正，也不能由一次行情或少量交易证明。当前 10,000 USDT、Binance 以及 BTC/PAXG/SPY 三个实验暴露都只是现役实验边界，不是永久资产域、基准或仓位尺度。

## 2. 设计删减原则

一个长期概念只有同时满足以下条件才能存在：

1. 拥有不能由相邻概念表达的独立不变量；
2. 有明确生产者和消费者；
3. 能被持久化、重放、评价或恢复；
4. 删除它会破坏真实性、资本安全或可证伪性。

仅为了命名一个步骤、保存中间文本、兼容旧代码、给未来留扩展点或让目录对称而出现的概念，必须合并或删除。实现细节不能晋升为领域阶段；一个阶段内部可以有算法和政策，但不能因此建立第二条业务链。

## 3. 唯一投资闭环

```text
外部世界与交易场所
        ↓
Evidence → State → WorldModel → Forecast → PortfolioTarget
                                         ↓
                         RiskDecision → Execution → Account/Outcome
                                                           ↓
                                                       Evaluation
                                                           ↓
                                           只影响未来 Release 与权限
```

账户、订单和持仓事实从交易场所进入 Execution，再供 Portfolio、Risk 和 Evaluation 读取；它们不进入 WorldModel 或 Forecast 来改变对未来收益的判断。唯一投资链之外只有一条安全反馈：Market/Account 异常可以直接触发 Risk 形成只减险授权，再由同一 Execution 收敛真实账户；它不能创建 PortfolioTarget、增加风险或反向开仓，因此不是第二条 Alpha 链。Scheduling 只唤醒闭环，Governance 只冻结和发布政策，Decision Cycle 只编排交接，三者都不创造投资判断。

闭环中的最少概念如下：

| 概念 | 唯一职责 | 明确不负责 |
|---|---|---|
| `Evidence` | 保存原始市场、事件、官方、账户和成交观察及其可见时间 | 解释因果或预测收益 |
| `State` | 对 Evidence 做点时规范化和确定性压缩 | 自由叙事、仓位和订单 |
| `WorldModel` | 维护当前最佳、可证伪的跨域因果解释 | 输出买卖、仓位或精确收益 |
| `Forecast` | 对冻结可交易收益对象给出可结算分布 | 过滤负观点、计算账户规模或下单 |
| `PortfolioTarget` | 从当前账户状态、现金和候选收益中选择唯一目标组合 | 改写预测、放宽风险或制造订单 |
| `RiskDecision` | 对目标组合批准、缩减或拒绝，并在必要时约束当前敞口 | 创造 Alpha；独立于新 PortfolioTarget 的保护动作只能减险 |
| `Execution` | 把已授权目标安全收敛为交易场所真实状态 | 修改世界解释、收益预期或风险上限 |
| `Outcome/Evaluation` | 结算预测、决策、执行和资本结果 | 用结果回写历史或在揭盲后修改计划 |

`Mandate`、可投资域、Reference Policy、`ForecastContract`、成本口径、评价方案和权限是 Governance 冻结的政策，不是新的运行阶段。程序模型和 Codex 是 Forecast 的可替换生产者；先验、校准、收缩和来源选择是 Forecast 内部政策；多头、空头、现金和继续持有是 Portfolio 的候选状态；订单组是 Execution 的恢复单元。它们均不得扩展为平行投资链。

## 4. 稳定业务语义

### 4.1 点时真实性

每项输入至少保存 `event_time`、`observed_at`、内容身份和来源身份，并满足：

```text
event_time <= observed_at <= decision_as_of
```

原始观察、规范事实、状态、认知、预测、资本目标、授权、订单观察和结果都追加保存。修订产生新版本，不能用今天获得的资料覆盖过去，也不能用后到成交覆盖当时未知的订单状态。

同一上游事件在采集器或规范化行为升级后可以产生多份不可变 Evidence 修订，但它们不能在当前决策或网页时间线中伪装成多个现实事件。Information 以来源提供的稳定文档身份（当前只在来源与其稳定 URL 原值均相同时成立）区分“新观测”与“新信息”：每次观测永久保存；若其文本片段和资产路由已被该文档此前的点时版本完整覆盖，则不再产生 Trigger，也不能用缩水副本替换当前投影；含有新增正文、修订命题或新增路由时才成为下一份可见修订。DecisionPacket 与 Dashboard 复用这一唯一投影。底层修订仍可按身份精确恢复，不做标题相似度、跨来源合并或 AI 去重；没有稳定上游身份的 Evidence 保持独立，避免误合并不同更新。

### 4.2 世界认知与预测

WorldModel 解释“哪些力量正在起作用、如何传导、什么会推翻解释”，Forecast 回答“某个冻结收益对象在冻结时域内的结果分布是什么”。两者必须分开：复杂叙事只有转化为可结算 Forecast 后，才可能影响资本。

分析提示词不是业务规则容器。Evidence 资格、点时窗口、字段结构、机制生命周期、预测期限、bucket、成本和资本权限分别由其领域的类型与合同拥有；AI 的固定任务只负责在这些冻结边界内进行联合因果推理。所有 target 的精确期限只读取 `ForecastContract.horizon_minutes`，不得在通用 posterior 提示中写死。某次事件漏判不能产生一条事件专用提示或第二条“快速认知”链；应沿唯一闭环定位是采集延迟、State 表达、因果推理、期限合同还是费用后资本映射失效，并只修复该唯一所有者。提示、模型输入投影和 Schema 的变化都属于 producer 行为变化，必须建立新的前瞻 cohort，旧结果不得混算。

外部主体的公开表态、市场对其行动路径的定价和该主体可观察的行动能力必须是三类不同 State：前者表达意图，第二类表达预期，第三类只压缩资产负债表、融资成本、到期义务、法定权限和已用工具等可验证约束。程序不得从能力状态直接写出“必然行动/无法行动”或资产方向；WorldModel 在同一通用因果任务内比较兑现、预期管理、协调与误读等竞争机制。任何主体和事件都复用这一语义，不建立人物、机构或单次讲话专用分支。

机制验证测试用于约束和评价 WorldModel 如何修正自身，不是 Portfolio 的隐藏有效性规则。新的 Evidence 可以让 AI 延续、修正、退休或新增机制，但任何 WorldModel 文本、机制身份或结构变化都不能直接判旧 Forecast 失效，也不能触发换手；否则会形成绕过 Forecast 的 `WorldModel → Portfolio` 第二条 Alpha 链。需要改变收益判断的新信息必须形成一份新的可结算 Forecast，紧急市场或账户风险则只能经程序化 Risk 形成只减险动作。

完整 WorldModel 永久保存。Forecast 只读可由 `world_model_id` 追溯的目标高密度投影，不建立第二套认知状态；Portfolio 只读取 Forecast 自身冻结的概率、可用时间、产品、时域和有效期。旧 Forecast 由新 Forecast 接替或按自身合同到期，不因后续 AI 改写因果叙事而被旁路撤销。

机制的 `next_review_at` 是 WorldModel 更新调度承诺，不是 WorldModel 或 Forecast 的失效时钟。到点只触发新认知生产；在新认知实际可用之前，点时系统继续使用当时最新的旧认知并保留其身份，不能先写入 `WORLD_MODEL_STALE` 来等待刷新。输入事实是否仍可用于推断由各自来源时效合同表达，机制是否被反驳或退休由下一份 WorldModel 表达，二者都不得由 Forecast 编排层重复裁决。

Forecast 在结果发生前绑定：收益对象、信息截止、完成时间、时域、结果定义、输入身份、生产者行为和结算方法。正、负、中性、不确定及最终未交易的 Forecast 都进入同一 Outcome 账本。生产者不能以费用后 Edge 或当前无持仓为由省略预测。

Forecast 预测的本体是连续的规范毛收益；`bucket` 只是为了让程序和 AI 共享概率分布的有序编码，不是把收益压成“方向命中”。合同必须同时永久结算真实收益 bps；边界、代表值和基准概率只能由开发带或数据无关的经济规则事前冻结，不得读取验证、盲测或前瞻结果后再定义标签。需要从 bucket 概率还原期望收益时，代表值必须是开发带对应桶的条件均值，而不是中位数或人为中心点。有序分布的主 Forecast 评分必须对距离敏感；无序 multiclass Brier 可保留为概率校准诊断，但不得单独选模或授权。

ForecastContract 还必须通过唯一 Product 投影做“资本分辨率”验收：在合法产品当时可能的 break-even 附近，不能让同一宽桶的代表值持续同时代表“应该交易”与“不应交易”的收益。该验收只判断 Forecast 编码是否丢失了下游需要的信息，费用仍只由 Product/Portfolio 计算一次，不进入 AI 输入也不反向改写经济 Outcome。若有限桶在不增加一条资本链的前提下无法通过验收，才将同一 ForecastContract 升级为连续 CDF/分位数表达；不为单个资产手写特判。

用于预测或资本权限的 Outcome 经济起点不得早于 Forecast 实际可用时点；来源需要同口径比较时，合同可以冻结一个晚于共同完成期限的统一决策锚点。`information_cutoff → Forecast 可用` 期间已经发生的收益不可交易，采用更早起点的历史标签只能作为行为诊断，不能贡献权限证据。Portfolio 与资本 PnL 始终从当时真实可成交锚点或实际成交开始。

ForecastContract 可以跨行为共享，但每个决策槽在到期前必须不可变地绑定“哪个 producer behavior 对该槽负有应答义务”。某行为的覆盖率分母只包含分配给该行为且已经到期的槽，分子包含同一批槽的 Forecast 与明确 `NO_ESTIMATE`；不得把旧行为槽计入新行为分母，也不得从第一条成功结果反推行为起点以隐藏漏报。ProducerBinding 首次登记时冻结行为激活点；登记行为身份不等于创建槽、义务或结果。组合所有者首次正常运行时必须同时登记已经装配的联合 prior 与 posterior，后续仅部署代码或前端的等价 Release 继续使用该激活点；只有 producer behavior 身份改变才建立新行为起点。激活前已经开始的槽不得追记为漏报。

每个槽与 producer behavior 最多拥有一个终态结果：Forecast 或 `NO_ESTIMATE`。迟到 heartbeat、重启、Pipeline 切换和漏报恢复都只能确保该结果存在；若任一终态已经存在，必须原样接受并继续本轮账户复核，不能把已有 Forecast 改判为漏报，也不能因新 Pipeline 尚无资本回执而拒绝旧结果。

同一经济问题在一个决策时点最多只有一个获得资本权限的 Forecast。若存在多个来源，它们在同一合同和 Outcome 下评价；只有前瞻证据证明组合优于单一来源后，才允许发布组合政策。来源差异不能产生不同标签、不同成本口径或不同资本入口。

研究 Forecast 复用同一 Contract、DecisionSlot、ProducerBinding、Forecast/`NO_ESTIMATE` 和 Outcome 账本。需要异步 Codex 的候选只持久化一份冻结 assignment 作为工作义务，成功或失败直接终结公共 Forecast 槽；禁止再复制一套候选结果表、结算器或资本流水。assignment 必须在任何候选调用前保存完整模型输入、Prompt、Schema、来源行为、截止和研究权限，worker 不得在执行时重新读取“最新”市场、世界认知或 Quant 状态来改写输入。一个研究 producer 的冻结输入依赖同槽程序 prior 时，装配必须按依赖拓扑先终结 prior，再运行会登记 assignment 的 preflight；不能依赖列表碰巧排序，也不能用事后补扫、重试或当前数据回填缺失输入。研究 assignment 的缺失或持久化故障必须记录并降低该候选覆盖率，但不能阻断、延迟或改写唯一资本 Forecast。

全部异步研究性 Codex 评价共用一条串行执行通道和一个短周期 assignment 发现间隔；它们可以在截止内排队，但不能并发占满账号而使 WorldModel 或正式 Forecast 无法启动。assignment 间隔只负责发现已经冻结的工作义务，不能变成各候选重复配置的调度政策，也不能复用较慢的 Outcome 结算周期给每项研究平白增加等待。该约束只隔离研究流量，不限制正式调用次数，也不是 AI 用量预算。

程序化 Forecast 候选的历史筛选必须同时回答概率分布是否更准确、其连续收益排序是否可能跨过现实成本。前者使用距离敏感 proper score，后者在验证带上检查预期收益排序、信号持续性、换手及按计划事前冻结的保守成本包络；任一关键时间相位不稳定就先淘汰，不为弱概率改善消耗 Codex 和前瞻样本。缺少历史可成交深度、时变规则或真实 funding 时，保守成本包络只能作为否决性筛选，不能冒充精确资本回放、不能授予权限；幸存候选仍进入现有 Forecast 账本和独立前瞻逻辑账户，以真实点时产品事实、完整成本和同一 Portfolio/Risk/Execution 语义裁决。这里不建立第二套策略、账户或评价链。

任何校准、收缩、来源选择或权限计算只能读取严格早于本次 information cutoff 且已经结算的 Forecast—Outcome；本次及更晚 Outcome 只能影响未来决策。输入样本身份和政策版本必须随 Forecast 保存，不能用事后更新的“最新校准”重写当时资本判断。

### 4.3 组合目标

Portfolio 每次解决同一个问题：从已对账的当前组合出发，在继续持有、现金和合法候选目标之间，选择现实成本与约束后的唯一目标组合。

#### 4.3.1 总组合而非单笔策略

Mandate 先冻结记账本位、实际购买力目标、投资时域、可用流动性与提款需要、可容忍的回撤/尾部损失/永久损失、杠杆边界和允许的经济暴露；它不预先规定必须持有哪些资产类别或战略权重。可投资域再把经济暴露映射到当时真实可交易的 Instrument，并且不得超出 Mandate 允许范围。记账本位只统一核算，不等于经济上无风险：当前 USDT 余额仍有美元购买力、稳定币发行人、脱锚和交易场所风险，必须进入 State、压力测试与评价。现金、利率、增长、通胀、信用、权益、商品、外汇和加密网络等才是风险收益来源，Spot、Perpetual、ETF 或未来其他场所产品只是实现工具。同一经济暴露存在多个产品时，只保留费用、流动性、跟踪、税费、funding、保证金和场所风险后最有效的合法表达；不能因产品数量增加而重复计算分散化。

Mandate 中无法从市场数据推导的偏好必须来自资产所有者：可追加或提取的现金、真实购买力参照、可接受的永久损失和回撤、杠杆与法律限制。`APPROVED` Mandate 还必须冻结可计算的购买力契约：权威来源与序列、币种/消费范围、发布滞后、修订和缺失处理、外部申购/提款与投资收益的分离规则，以及目标时域。Mandate 绑定这份长期计量契约，Reference 计划只能冻结当次符合契约的数据集哈希；它不得自行选择 CPI、换一个国家或重定义现金流。只写 `REAL_CAPITAL_GROWTH` 字样而没有这些口径，不能评价目标是否实现。Agent 可以指出目标内部矛盾、提出更稳健的候选并运行隔离模拟，但不能根据近期行情、模型输出或为了产生订单静默改写这些边界。信息尚不完整时只能登记明确版本的临时 Mock Mandate；它可以用明示的假设口径验证全尺寸模拟经济性，即使候选通过技术评价，Release 也不得据此登记总组合 Reference 或授予正式资本。Mandate 不是频繁优化参数，只有资产所有者约束改变或长期证据推翻其实现假设时才建立新版本。

观察域可以大于可投资域。系统必须理解无法直接交易但会影响组合的利率、财政、信用和跨资产事实；只有通过产品语义、市场时段、容量、账户权限与执行验收的 Instrument 才能进入 Portfolio。若当前 Venue 无法提供足以构造目标组合的经济暴露，系统必须暴露 mandate/Venue 不匹配，不能把若干高度相关的币或长期持有永续合约伪装成多资产配置。

WorldModel 的组合目标集合必须由可投资域编译为唯一的 `mandate_exposures`，而不是复用行情 symbol 列表。用于验证传导的 `observation_assets` 是独立的只读观察合同：它可以含不可交易代理，也可以不含缺少合格直接行情的组合产品；缺少直接观察只能降低对应机制边界，不能把该暴露从组合目标中删除或伪造一份 Spot。WorldModel 只维护跨暴露联合机制，不输出 observation asset 的方向预测；每个可投资经济暴露的概率判断只由 ForecastContract 产生一次。应用装配必须验证组合目标与可投资域精确一致，并把两类身份都纳入 AI 行为哈希和前瞻实验换代。

广域信息的保存资格与立即唤醒资格必须分开：新闻中唯一新增命题若只是系统已经直接观测的价格、涨跌幅、成交或波动复述，仍可作为来源事实保存，但不再通过 External Information 重复唤醒 WorldModel；相应变化只由 Market 的同窗冲击事实触发。未计划的外生事件只有在来源提供可验证的结构化事件/重要性元数据、来源本身是事前冻结且可回放的高召回市场快讯合同，或一个已证明召回与精度的点时分类行为确认后，才获得立即唤醒资格；无法确认时进入下一次自然认知窗口。不得用不断增长的热点词、标题长度或来源 rank 反向授予资格，也不得因为抑制调用而丢弃原始事实。唯一 TriggerPlan 可以用 rank 合并已经合格的弱线索并限制调用频率，但这只是资源调度，不是事件重要性、证据升级或 Forecast 资格。来源/分类行为长期没有改善认知时延后的 Forecast 或风险解释，就撤销唤醒资格并删除专属实现。

信息合同有四项正交语义：`attention_priority` 只决定有限面板中的发现顺序；`immediate_review_eligible` 只授权事件到达后调用 WorldModel；`directional_support_eligible` 只陈述 Evidence 能否进入因果证据；`material_forecast_eligible` 只在不可变 Trigger 中冻结本次变化能否形成事件 Forecast。前三项属于 Evidence，最后一项属于触发政策；四者不得互相推导。来源合同绑定稳定发布流而不是 MCP、HTTP 等获取传输；同一发布经两条路径到达时必须得到同一复核资格，返回顺序不能改变 AI 行为。当前一条可回放的 NewsNow 快速流获得高召回认知唤醒资格，但保持非方向、非材料，第二条聚合流只保存和交叉核验；官方发布终态、程序化市场冲击和主 Agent 明确请求继续使用各自既有的直接触发合同。日历到期只履行 Information 获取义务，不能在官方内容尚不可见时调用 AI。Dashboard 不把发现优先级展示成“现实影响”。

产品准入必须区分估值与可执行性。原始报价、指数价或最近成交可以在休市时继续用于带质量标记的账户估值，但只有命中当时官方交易日历、深度和交易规则的双边报价才能形成 `ExecutableQuote` 并进入 Portfolio、Risk 或 Execution；休市旧报价、只有标记价的合约和未来才生效的交易时段都不能生成订单。两种语义可以读取同一份 Market 事实，却不能共用一个会把“可估值”误写成“可成交”的值对象。可投资域只表示产品可能被选择，不等于每轮无条件依赖其行情；账户估值只请求当前持仓和 pending execution 涉及的产品，本轮决策再请求实际 Forecast target 的可执行报价。无持仓、无 pending、无方向权限的产品不得扩大其他资产或纯现金复核的故障半径。新增产品必须先完成日历、现金流、funding/分红、合约乘数、取整、容量、故障恢复和点时回放，再进入可投资域。

总组合可以跨多个 Venue，但仍只有一个以总财富为分母的账户事实和一个 PortfolioTarget。各 Venue 的现金、证券、保证金、借贷、应计利息、funding、未结算现金流和托管风险只是 Execution 所有的可对账子账本；统一估值必须使用点时汇率和可成交退出价格，不能把转账途中资金重复计入，也不能把稳定币、法币现金和货币市场暴露视为同一种无风险现金。增加第二个 Venue 时只实现已经选定产品所需的最小账户、行情、订单和恢复契约，不提前建设通用 Broker 平台。

同一账户必须同时保留三种不可互换的量：净资产回答“现在值多少钱”，产品有符号名义暴露回答“承担了多少市场风险”，未抵押且压力后仍可用的流动性回答“还能履行多少现金义务”。Spot 买入减少现金并增加资产退出价值；Perpetual 的名义金额形成经济暴露，却不是一项等额资产，其保证金仍属于账户现金但不再是自由流动性，盈亏和 funding 才改变净资产。Reference 中有意保留的经济现金是风险暴露目标的剩余项，不等于账本看到的全部现金；为衍生品提供融资或抵押的现金不能同时再次算作独立现金风险配置。因此不得用一个通用 `weight` 同时表达资产持有、衍生品名义、经济现金和保证金，也不得把账本现金比例与 Perpetual 名义比例相加后声称资金恰好为 100%。在纯全额 Spot 组合中三者可以退化为熟悉的资产权重关系，但公共合同必须按更一般的产品语义定义。

经济现金只有一个 Portfolio 语义，现金管理不是 Forecast、Alpha 或第二条资本链。Portfolio 确定目标经济现金，Risk 扣除当前保证金、未结算现金流、提款与压力缓冲后，产品投影才可以让剩余现金在自由结算现金和收益型现金产品之间选择现实表达；Execution/Account 负责申购、赎回、收益计提、估值与对账。收益型现金仍承担结算资产、发行人、场所和赎回风险：本金与已确认收益可以按显式 haircut 计入净资产，却不能在成功赎回到账前计入可立即动用流动性，也不能用预期收益提前增加权益。赎回延迟或失败时必须保持原产品状态，不能同时生成自由现金。

收益型现金产品只有在同一时点具备账户资格与额度、APR 与奖励币种、申赎费用和到账延迟、流动性限制、估值/计提/对账规则以及发行人、场所、脱锚和压力处理时才可进入产品投影。自由现金与收益型现金之间的转换比较必须包含损失的收益、申赎费用、币种转换、未完成义务和错失交易机会，不设置固定预留额、固定持有期或独立轮询节奏。转换只能由同一资本决策、账户恢复或产品规则实质变化触发，不允许现金收益机制自行创造方向仓位或高频搬运。没有合格 Forecast 时，已被 Portfolio 判定为经济现金的部分仍可获得现金收益；这只改善现金实现，不证明方向 Alpha。

Mandate 与可投资域各只有一个版本化权威身份。Cognition 可以读取更宽的观察投影，ForecastContract、Portfolio、Risk 与 Execution 只能读取由同一身份编译出的合法产品投影，并可按各自安全职责进一步收窄，不能在多个配置段各维护一份事实来源不明的 symbol allowlist。任何新增产品都生成新可投资域版本；旧 Forecast、Target 和 Outcome 继续引用当时版本，不被当前列表重解释。

Portfolio 不建立“被动核心仓”“AI 仓”“多头策略仓”和“空头策略仓”等平行资本池。长期风险溢价模型形成 Forecast 的中性收益先验，WorldModel 和其他已验证信号只对先验形成有期限、有不确定性的条件修正；Reference Policy 则独立表达 mandate 允许的总风险及低成本可投资基准。三者各有不同语义，但正式资本最终只进入同一个 PortfolioTarget。Reference Policy 合法、可执行且账户风险正常时，没有可信主动观点意味着回到 Reference Policy，而不是退回纯现金；只有 Reference Policy 缺失或失效、资产所有者需要流动性、产品不可执行或风险包络要求收缩时，现金才成为目标。AI 无须为长期有报酬的中性暴露持续制造方向理由，也不能仅凭沉默清空它们。

#### 4.3.2 组合 Forecast 与稳健取舍

单产品实验可以使用标量 Forecast；多资产决策必须在共同信息截止和资本决策时域下冻结一组可联合结算的收益分布。长期风险溢价、周期状态和事件冲击可以拥有不同原生时域，但必须先按各自持续性衰减或投影到本次共同资本时域，无法合理投影的观点保持分离而不参与本次权重优化；不能把 4 小时观点和季度风险溢价直接相加，也不能让短期噪声清空长期暴露。机制进入某个 ForecastContract 前必须具有事前冻结、可点时复算的“机制原生时域 → 合同 Outcome 时域”投影支持；仅在文字中声明 12 或 24 小时影响，不能让模型临场猜测其对 4 小时 bucket 的缩放。没有任何机制落在合同支持域时不创建 AI assignment，已有程序 Forecast 照常形成并结算；该资格只由行为冻结的时域与映射决定，不能按本轮方向、强弱或事后结果选择性跳过。Forecast 先表达各合法经济暴露相对一项可点时结算的规范参考价格或指数的保守收益分布、预测不确定性以及共同情景或相关结构，再由同一 Forecast 领域把它确定性投影为各合法 Instrument 的未来 payoff 分布。该分层符合[机构组合构建把投资观点、暴露、风险和交易实现分开的实践](https://www.msci.com/downloads/web/msci-com/research-and-insights/paper/the-common-language-of-portfolio-construction/the-common-language-of-portfolio-construction.pdf)，但不新增服务、第二条资本链或每产品一次 AI 调用。波动、相关性、流动性和成本由点时程序状态估计；AI 适合形成跨域情景概率和相对/绝对收益观点，但不能用叙事直接输出名义金额。确定性融合把主动观点按其前瞻校准和不确定性收缩到中性先验；无证据的新行为不得影响 official 资本，但可以在预登记 Mock 资本包络内获得有界实验权重，以形成真实组合证据，不能凭自报信心放大仓位。

同一次组合 Forecast 调用只携带一份共享世界认知与覆盖边界，并为每个经济暴露携带一份紧凑合同、点时价格状态和相关衍生品状态。完整 ForecastContract、WorldModel 维护字段、重复因果节点和 raw market data 留在不可变账本，不在目标之间重复发送；模型仍能看到机制 claim、证据索引、冲突证据、结果桶和基准分布。发布测试必须按“固定指令 + 全部现役目标 + 最大合法 WorldModel”检查最终提示词并保留余量，不能放宽运行时上限、截断输入或等到生产槽才发现容量故障。

联合 Forecast 的最小不可变内容是：共同截止与时域、成员经济暴露及规范参考 Outcome、每个联合情景的概率与成员收益、来源/行为身份、输入引用和缺失结果。边际预期、协方差和尾部损失从这份联合分布确定性派生，不另外维护一套可漂移数字。经济 Forecast 在结算前保持不变；产品 payoff 只是 Forecast 领域在某一资本决策时点形成的派生事实，必须绑定当时的 Instrument、可成交锚点、参考价格映射、basis/funding/现金流假设、映射不确定性和产品规则引用。只要源 Forecast 的经济时域仍支持决策，每次新建、持有、减仓或切换比较都用当前可得事实重新投影；`valid_until` 之后形成的投影只能支持不增加经济暴露的持有、减仓或产品转换，不能绕过原 Forecast 的入场窗。每个旧投影继续不可变保存，但不能因 `source_forecast_id + target_id` 相同而阻止新时点版本；投影自身的短期有效期来自产品事实新鲜度和本轮资本决策期限，不复制源 Forecast 的入场窗。新投影只包含决策时点之后尚未发生的 funding 和现金流，已经结算的部分属于 Execution/Account 事实，不能再次计入未来 payoff。缺少任一必要状态时该 Instrument 没有当前候选，而不是复用旧投影或让 AI 补猜；若账户已经持有该精确产品目标，只能读取同一源 Forecast 最近的不可变投影恢复目标和经济血缘，并把本轮缺失冻结为产品输入失效，使 Portfolio 只能经唯一 Risk、TradePlan 和 Execution 链减仓，旧投影不得继续授予持有或加仓资格。Forecast 中的多腿只允许表达一个不可拆分 payoff，例如需要原子执行和共同结算的价差；它不能用预设 `gross_weight` 偷渡资产配置，普通多资产权重始终由 Portfolio 决定。

衍生品规则以交易所完整产品目录为准，资金费率信息端点只作为明确调整过的 interval/cap/floor 稀疏覆盖，缺席不能被解释成产品不存在或擅自补成默认值。若经济时域内存在尚未发生的 funding，优先使用点时可见 override；没有 override 时只允许从已经可见的连续常规结算间隔推导，无法推导则该产品失败关闭。每次成功规则轮询都保存新的点时观察，即使有效内容未变；连续失败不会刷新成功时间，规则超过冻结年龄后自动失去候选资格。该年龄由产品投影读取同一规则事实，不建设第二套 freshness 服务。

Portfolio 以当前总财富为统一分母，只读取 Forecast 已形成的产品 payoff 投影，选择使保守的费用后长期增长最优、同时满足尾部和生存约束的产品有符号目标暴露；它不能自行把经济观点翻译为未验收产品。实现可以采用约束均值—方差、情景效用或其他经样本外证据胜出的算法，但都必须显式包含：预期收益估计误差、产品映射误差、协方差或共同尾部、现有持仓、经济现金、全量未来成本、可用流动性、funding、保证金和换手。产品映射、basis、funding 与保证金的不确定性必须改变情景 payoff、尾部或保守包络，不能只从期望值机械减去一个标量后让 Risk 看见虚假的窄分布。Reference 可以让各项经济暴露与经济现金合计为 100%，但现金不是交易 Leg，也不等于产品账户的原始现金余额；产品编译根据同一目标分别产生 Spot 资金占用、Derivative 名义和保证金，并把衍生品的融资储备在资本配置上归属到对应风险暴露，避免再次算作中性现金。这种归属不会消除该储备真实承担的结算资产、托管、脱锚和压力流动性风险；Risk 仍按实际资产和抵押状态计量，不用战略归属抵消。优化器不能把一个微小而不确定的均值差放大成极端集中度；简单分散、最小方差或 Reference Policy 必须作为同风险基线参与竞争。

资本计算只有一个语义，可用下式表达而不能拆成两套账户：

```text
中性先验 + 经校准且按不确定性收缩的条件观点
        → 联合费用前收益分布
        → 在 Mandate 与产品约束下求一个稳健目标暴露
        → 扣除从当前权重迁移的完整成本与不确定性缓冲
        → 唯一 PortfolioTarget
```

`Reference Policy + 主动偏离` 只用于解释最终权重从哪里来，不表示存在“被动仓”和“AI 仓”。主动偏离必须以相对 Reference Policy 的边际收益、边际风险、共同尾部和跟踪风险计量，并随观点校准不足而连续收缩到零；绝不能让若干独立信号按各自名义金额抢占账户。若复杂优化器在点时样本外不能稳定胜过 Reference Policy、简单分散或最小方差候选，则删除复杂实现而保留简单规则。

#### 4.3.3 仓位、方向与再平衡

仓位尺度来自整个账户的目标经济暴露和风险贡献，不来自固定“单次交易金额”。总风险包络先限定可承受的组合波动、压力损失、回撤、gross/net、保证金和压力后可用流动性，再由 Portfolio 在包络内分配目标；Risk 只负责缩减越界结果。固定美元上限只能是某个实验的资本授权，不能成为长期 sizing 公式。最小订单金额和最小再平衡差只用于避免无法成交或成本不经济的碎片订单。

任一订单的经济金额只能由 `总权益 ×（目标有符号暴露比例 - 当前有符号暴露比例）` 经产品乘数、汇率、可成交深度和取整得到；随后还必须满足 Spot 现金、Derivative 保证金和压力流动性约束。模拟盘与正式盘在 Portfolio 层使用同一目标暴露，因此“模拟”本身不能把应有的 10% 或 20% 账户暴露缩成几十 USDT；几十 USDT 只可能是明确登记的技术 Canary，不得进入全尺寸策略收益评价。反过来，账户规模较小也不构成满仓或放大杠杆的理由：若风险预算只允许 3%，正确仓位就是 3%；是否有经济意义由预期净改善相对估计误差和完整成本决定，而不是由用户期望的订单观感决定。

账户较小时，多资产不意味着机械均分、持有每一类资产或按资产数量证明分散。固定成本、最小订单和估计误差会使最优组合保持稀疏：只建立少数能显著改善总组合风险收益的暴露，每项金额仍由总权益、边际风险贡献和不确定性决定；分散是否真实由共同情景中的风险贡献、流动性和尾部相关决定，不由币种、产品或“经济暴露数量”计数决定。对线性产品，若建议增量小到无法在完整成本后对总组合收益或风险产生可辨识改善，就把该增量归零，而不是为了展示“有交易”保留几十 USDT 的装饰性仓位；真正有价值的暴露应按目标风险获得有经济意义的账户权重。方向同样不是目标：做多用于承担有报酬的风险，做空用于表达经验证的负收益或降低组合风险；做空产品若在 funding、basis、强平和场所风险后不改善总组合，就保持现金或减仓。

Portfolio 每次从当前产品暴露向目标暴露交易，而不是清仓后重建。长期先验、周期状态和突发事件可以按各自原生时域更新，但只能在投影到同一资本决策时域后共同改变这一个目标。只有当目标变化的保守收益改善超过完整转换成本和不确定性缓冲，或现有风险越界时才再平衡；交易发生在经济无交易区间被突破时，不由固定日历或订单次数驱动。

Forecast 的 Outcome 时域、Forecast 采样 cadence 与资本重决策频率是三种不同语义。Outcome 时域回答预测在什么终点结算，采样 cadence 回答何时形成可评价的新判断；只有随 `capital_behavior_id` 和 Authorization 冻结的资本控制规则，才能决定哪些 Forecast cause 可进入 Portfolio、一个新观点何时替代仍有效的旧观点，以及两次允许增加风险的决策之间采用哪一份联合分布。该规则直接属于资本行为，不新增 Holding、Cooldown 或第二套调度状态机；未被规则选中的 Forecast 仍照常结算和评价，但没有资本处置义务，也不能因 AI 调用更频繁而改变仓位。材料事件只有在同一冻结规则事前授权时才能提前重决策，账户与市场硬风险则始终只能独立减险。

资本控制规则必须与 Forecast 的经济时域自洽。采用低频锚点时，入选 Forecast 的剩余时域必须覆盖本次资本决策区间，不能用 4 小时期望收益支撑一项预定数日后才复核的新增暴露；采用重叠时域的滚动控制时，每个新 Forecast 可以按冻结替代规则重算目标，但评价对象必须是这整条按时间顺序运行的账户政策，完整计入所有翻转、持有、退出和再进入成本，单次 Forecast 的到期收益或局部正 Edge 不能证明该政策可盈利。面向当前长期 Mandate 的正式总组合必须采用日度状态、周度或双周资本锚点和经授权的材料事件复核；更短周期的 Forecast 可以作为组件或 Shadow 控制实验积累证据，却不能沿用长期总组合身份或资本结论。

同一经济暴露存在 Spot、Perpetual 或其他合格表达时，Portfolio 比较的是“保留当前表达、切换到替代表达、减少暴露、回到现金”这些完整账户状态，而不是先选产品再单独判断平仓。切换收益必须扣除旧产品退出、新产品进入、未来退出的全部尚未发生成本以及过渡期风险；最终 PortfolioTarget 对该经济暴露只保留一个产品表达。若切换胜出，Execution 以关联订单先减少旧表达并按成交事实释放风险，再建立新表达；Risk 必须约束部分成交期间的瞬时 gross、方向、保证金和流动性。执行合同还不能安全完成这种转换时，正确结果是拒绝切换，不是同时持有两个长期表达，也不是把替代候选静默当成普通重复项。

成本以“当前状态 → 目标状态”的变化计算：开仓、持有、退出和反转分别只计尚未发生的费用、点差、滑点、funding 和其他现金流；已发生费用是沉没成本，不能重复扣除。Portfolio 使用当前可成交事实重估 Forecast，Codex 运行期间已经发生的价格变化不能计作可赚收益。

这不是按动作名称分支的多套公式。对统一的评估金额，当前持仓中继续保留的部分以当前可成交退出价重估，新增部分以当前可成交入场价重估；费用只覆盖本次增减仓与目标暴露未来退出，深度惩罚只覆盖这些尚未发生的成交。于是新开仓自然包含入场与未来退出，原仓不再重复入场成本，减仓包含当下减仓与剩余目标未来退出，清仓只包含当下退出。报价已经按可成交退出侧计量的当前权益不再重复增加一次当下点差。

PortfolioTarget 必须冻结本轮全部合法候选与现金比较所使用的点时经济事实，而不只保存最终目标：Forecast 与产品 projection 身份、当前与评估名义金额、可成交报价引用、剩余毛 Edge、尚未发生的完整成本、净 Edge、适用门槛、资格结论、拒绝原因和最终目标金额。Dashboard、回放和评价只能读取这份不可变比较，不能用当前授权、成本、配置或行为重算历史；旧版本没有保存且无法从冻结制品无歧义恢复的字段明确标为缺失，不得猜测回填。

资本选择、错过机会与费用后结果必须按冻结的 `capital_behavior_id` 分 cohort 评价。可投资域、产品映射、Portfolio 规则、成本或 sizing 任一实质变化后，当前证据只读取新身份产生的完整决策；旧目标与结果继续不可变结算并保留在历史行动审计中，但不得冒充现役盈利诊断、与新候选拼成比较，或把旧产品重新显示为当前可投资表达。

预测 Alpha 与产品映射是两项独立实验，不能共用一个含混的“当前版本”。经济 Forecast 只按冻结的 `producer_behavior_id` 累积 proper-score 证据；确定性产品映射则按当前配置中完整的 `(economic_exposure_id, projection_version, instrument_keys, maximum_rule_age_seconds)` 集合生成内容身份并累积残差证据。该身份必须随 projection 在数据库中原子冻结；改变产品集合、basis/funding 规则或映射实现时，不得重标相同 AI 概率或清空预测证据，但现役产品残差必须立即开始新的映射 cohort。旧 projection 与 outcome 继续不可变结算，只能进入历史审计。产品证据的数据库查询和领域评价边界都必须校验完整 cohort；同一 projection ID 不能绑定两个 cohort，不能只凭 AI 行为、单个版本字符串或当前产品恰好仍存在来拼接跨代样本。

同一经济暴露分布只产生一个预测样本。Forecast 可以从同一分布生成多个产品投影，不得再次调用 AI 或把产品数量计为多个 Alpha 样本；每个投影的跟踪误差与费用后资本结果仍分别结算。对于同一已经验收的线性 Derivative，规范 payoff 可以生成正负名义候选；Spot 不能直接生成负持仓，Spot 与 Perpetual、不同结算资产或不同场所也不能机械镜像。[Binance 的 mark/index 与 funding 合同](https://developers.binance.com/docs/zh-CN/derivatives/usds-margined-futures/market-data/rest-api/Mark-Price)必须进入 Perpetual 产品投影，未知的未来 funding、basis 和保证金压力以冻结模型和不确定性处理，无法可靠处理时拒绝该产品候选。

Forecast 的规范参考 Instrument、Market 的观察 Instrument 与 Capital 的可投资 Instrument 是三个不同集合。规范参考只定义经济 Outcome 的价格与结算口径，可以是不可交易的指数、代理或本轮明确不持有的 Spot；观察集合只提供状态和映射证据；只有可投资集合才进入产品投影、Portfolio、Risk、Planner、账户和持仓页面。引用某个 Spot 作为 BTC 或 PAXG 的规范价格，不得隐式把它加入账户候选；反过来，移除一个执行产品也不得改写已经冻结的经济 Forecast 合同。配置必须分别冻结这些身份并验证产品映射，禁止再用“规范参考必须属于 execution specs”把不同职责耦合起来。

每份产品投影无论是否被 Portfolio 选择，都从自身冻结的可成交入场锚点结算到源经济 Forecast 的共同终点；Spot 使用退出侧报价，Derivative 同时结算真实 funding，点时行情或资金费率在宽限期后仍不完整就永久记为不可用。现役研究 producer 的完整联合面板形成后，现有 Outcome Evaluation worker 在该 producer 的真实 `available_at` 为全部合法方向记录一次完整候选投影；它不等待资本授权或 Portfolio 选择，也不新增服务、账本或 Forecast，Dashboard 仍严格只读。产品映射评价不能直接比较“预测产品总收益”与“实际产品总收益”，否则源 Forecast 的方向误差会被错误归因给 basis、funding 或产品规则。对同一完整资本决策截面，先以同决策时点、同终点的规范经济参考消去已经实现的经济暴露收益，再比较产品相对该参考的预测与实现残差；当前 BTC 合同可使用 Spot，非现货经济暴露则必须由 ForecastContract 冻结可点时结算的指数、总回报序列或合格代理，不能把 Spot 写成跨资产前提。长短方向按有符号经济暴露对齐。只有完整联合面板冻结的候选集合才有产品排序语义，孤立或中途失败留下的 projection 可以结算和诊断，但不能由时间戳拼成一份完整产品选择样本。后续持仓复核投影仍永久保存和结算，却不能因触发更频繁而在主证据中获得更高权重。映射残差的误差与保守覆盖只裁决产品映射；相对事后最佳产品的 gross 后悔值只能诊断，不能授予选择权限。手续费、点差、滑点、未成交机会成本、保证金风险，以及实际选择相对现金、规范产品或冻结 Portfolio 基线的费用后增量，仍由 Portfolio/Execution 资本评价负责。源概率分布继续只用 proper score 评价一次，不因产品数量增加样本。

PortfolioTarget 是产品目标暴露的组合映射，不是订单集合。策略名、分析次数或预测来源不形成永久的“仓位对象”；只有确有独立执行原子性或评价语义的多腿实验，才可在该实验中引入组合腿定义，不能预建通用 Sleeve 体系。

#### 4.3.4 现役研究资本对照与模拟账户

系统只保留一条 Portfolio/Risk/Planner/Execution 语义，但必须区分三个消费者。`RESEARCH` Forecast 进入 Evaluation 的只读逻辑账户，用真实点时行情、产品规则、funding 和完整成本推进反事实资金路径；`CAPITAL_CANDIDATE` Forecast 才能进入唯一正式 Mock 账户；未来真实资金仍需独立 Governance 授权。逻辑账户不是第二套交易系统：它复用同一资本算法，不写 Venue、不产生持仓页面和订单，只回答候选当时若被执行会怎样。正式 Mock 订单只增加执行、对账和恢复证据，不能把同一行情路径上的结果重复算成 Alpha。

当前账户能力集合包含 BTCUSDT、PAXGUSDT 与 SPYUSDT 三个永续产品，因此页面持续显示三行并在无持仓时明确为零；这不等于三个产品都拥有现役 Forecast。当前唯一前瞻实验只有 BTC 与 PAXG 两份 72 小时经济合同：Spot 是各自 Outcome 的只读规范参考，USD-M Perpetual 提供程序化多空表达。SPY 仍属于账户和产品能力，缺少冻结的同口径 ForecastContract、独立 Outcome 与合格产品映射前不进入本 cohort，也不得用 BTC/PAXG 结论替代。PAXG 的外部黄金观察只用于辨别代理偏差，不改写已经冻结的 PAXGUSDT Outcome。

同一槽只调用一次 Forecast Analyst，输入一份同截止 WorldModel、两份合同和各自滚动无条件 prior，输出两份独立结算的 posterior；单个目标失败只为该目标留下 `NO_ESTIMATE`，不得补发第二次 AI 调用。每份合同的 bucket、代表值、历史窗口和可见时间独立冻结，不能复制另一资产边界。产品多空投影完全程序化，资产数、方向数和产品数都不能冒充独立预测样本。

现役 prior 与 posterior 均为 `RESEARCH`，当前配置没有 `CandidateCapitalAuthorization`，所以正式 Mock 账户保持全现金是权限隔离事实，不是市场判断、固定样本门槛或费用后选择。两条行为仍从相同初始资本分别推进独立逻辑账户：各自按真实 `available_at` 使用当时可成交价格，在正向产品、反向产品与现金间比较，并承担自己的延迟、换手、手续费、点差、滑点、funding 和强制退出。这样无需让两个相互竞争的行为同时写一个 Venue，也能得到费用后资本增量；有效 Forecast 到期后若未形成全部合法产品投影、现金比较和逻辑账户终态，才是系统缺陷。

资本比较只保留真实经济边界。全现金路径新增风险时，毛收益必须覆盖从当前状态到目标及终点退出的全部未来成本；已有仓位转为现金必须计入立即退出成本。现金不预留固定比例，仓位不按每资产固定额度或固定 bp 门槛分配；数量步长和最小名义只由产品规格拥有。Sizing 使用冻结产品分布的费用后上行和下行情景并受账户 gross、集中度、压力损失、保证金和回撤边界约束；多个合法目标超过 gross 上限时同时按比例缩放，不能按排名机械塞满少数产品。

Sizing 后必须重新比较当前持仓、建议目标与现金的共同终点财富，最终 `CandidateEvaluation`、目标与订单引用同一目标金额和同一成本事实。相邻 Forecast 导致的全部迁移在各自逻辑或正式账户中连续累计，不能把每个重叠 Outcome 当成独立交易；程序不得用冷却期、最短持有期、信心乘数或主观换手惩罚遮盖预测翻转，费用本身就是统一否决边界。逻辑账户和正式账户都不得为凑订单强制交易，未成交的正反产品仍在共同终点结算以识别正确持币、错误入场与错过的成本后机会。

只有前向评价证明某个唯一行为相对冻结基线提供可靠的预测与费用后资本增量，未来 Release 才能把它绑定为 `CAPITAL_CANDIDATE` 并接入正式 Mock 账户；这不是等待固定样本数，而是要求当前不确定性、覆盖、依赖结构和成本后结果足以支持该权限。`CandidateCapitalAuthorization` 是当前 Release 的治理授权，ProducerBinding 的 permission 则冻结某个槽产生时实际适用的准入事实；同一预测行为可以保留既有 `RESEARCH` binding，并从授权生效后的未来槽使用新的 `CAPITAL_CANDIDATE` binding，二者共享 producer behavior 证据但不得同时承担同一槽。权限变化不重写旧 Forecast、逻辑账户或正式持仓血缘，也不能靠更换 producer behavior 清空失败。Capital 不调用 Forecast producer 或 Codex，只读取已经由 Forecast 域终结、仍有效、精确属于该资本 binding 且共享同一信息截止的完整联合面板；研究 binding 下形成的旧结果不能因后来授权被追溯交易，缺腿面板也不能局部配资。若未来候选进入 Mock，仍复用本节的同一算法与账户风险边界，不建立 prior 账户、posterior 账户或资产专属交易链。

正式账户的历史成交由 Execution Evaluation 从终态组重建开平 cycle、持有时间、turnover、方向毛收益、费用与净收益，并与全平账户归因核对；逻辑账户报告同口径指标但不冒充真实订单。停止或替换行为只能作用于未来权限，不能按已经看到的盈亏动态改写同一 cohort。高水位回撤、压力损失、gross/net、保证金、对账和 Kill Switch 已经构成连续生存边界，不再叠加按 UTC 日重置的绝对亏损线或仅供 Mock 绕过的模式分支。

### 4.4 风险与执行

每个账户所有者触发都先查询是否存在尚未形成资本终态的新完整授权 Forecast 面板：存在时只消费一次该面板，不存在时仅做账户对账、持仓风险、继续持有、减仓或退出。触发名称本身不授予资本；同槽 posterior 对应的 `WORLD_MODEL_UPDATED` 只在 posterior 已成功或以 `NO_ESTIMATE` 终结后发布，普通 WorldModel 更新没有 Forecast 就只能触发复核，因而不会与异步 Forecast 竞态。即使旧 Forecast 尚在有效期内，也不得借 Heartbeat、信息写入、WorldModel 更新或 Agent 唤醒重复增加名义暴露。新增资本和扩大暴露只能来自新完成且精确匹配当前授权的定时或材料事件 Forecast，因为只有它们冻结了覆盖该信息集的方向概率。该边界不限制模拟盘探索：所有正式 Forecast 仍可自由比较全部合法多空产品并按费用后 Edge 配资；它只阻止陈旧推理被非分析触发器重复放大。

Forecast producer behavior 切换不能使既有仓位失去经济血缘，也不能把旧预测伪装成新候选。持仓复核继续读取建立该 Sleeve 的不可变 Forecast 和产品投影，只允许维持或减少其当前名义，不需要、也不得借用当前行为的 candidate capital authorization；只有当前行为新完成且精确匹配授权的 Forecast 才能新建或扩大风险。发布验收必须覆盖“旧行为仍有持仓、新行为尚无 Forecast”的切换窗口，确保风险复核可运行而新增资本保持关闭。

Risk 对同一冻结账户、行情和目标执行硬约束，输出批准、缩减或拒绝。保证金恶化或硬限额突破时，Risk 可以不等待新 Forecast，直接针对当前已对账敞口形成只减险 `RiskDecision`；它只能把各项授权上限向现金方向收缩，不能创建 `PortfolioTarget`、增加敞口、反向开仓或生成收益判断。账户数量未知或本地与 Venue 不一致时先冻结新增风险并由 Execution 对账，不能根据旧本地数量猜测减仓；权威敞口确认后才执行减险。

Execution 只接受获授权目标或只减险指令。它拥有交易场所账户、订单、成交、资金费用、持仓和对账事实，必须处理稳定订单身份、重复提交、未知结果、部分成交、重启恢复和主动对账。未确认减仓前不得视为风险已经释放；方向反转必须先平旧方向、对账为零，再开新方向。

资本执行只有 `simulated` 与 `official` 两种业务模式。二者在 Venue 边界以上复用完全相同的 Forecast、Portfolio、Risk、TradePlan、账户投影和恢复语义；差异只能是凭证、提交/查询、成交、余额、仓位、资金流水和对账来源。研究回放、Shadow 和 Testnet 是运行或验收属性，不得形成第三套投资逻辑。Official Venue 未达到这种等价性时必须失败关闭。

部署模式只由系统装配层选择 Venue 与权威账户来源。Forecast、Portfolio、Risk、TradePlan、资本行动 DTO 和行动文案不得接收、分支或提及“模拟/真实”；它们只处理资本资格、目标、约束、订单与成交。页面可以在全局环境标识和收益总览说明当前是模拟盘，但单条资金决策不能把运行环境冒充成决策理由或交易类型。

TradePlan 的短期有效期只约束“这次订单计划是否仍可执行”。Forecast 已有的入场有效窗和经济时域承担两项不同职责：`valid_until` 只决定是否还能新建或增加敞口，`economic_horizon_end` 决定这份 payoff 最晚何时仍可支持既有敞口。入场窗结束后，Portfolio 只能按当前可成交价重估并保持或减少原敞口，不得借旧 Forecast 加仓；到经济时域结束仍无更新 Forecast 时必须收敛到现金。PortfolioTarget 的短期有效期只要求重新计算目标，不等同于清仓时点。三者直接复用 Forecast、Target 和 TradePlan 的既有时间事实，不增加入场/持仓状态机。新资本决策按账户 revision 串行化；迟到分析永久保存和结算，但不能覆盖已由更新信息形成的目标。

Forecast 已经形成而资本阶段中断时，恢复仍必须在当前时点形成唯一的 PortfolioTarget 与 CapitalCycleRecord：入场窗内按当前可成交事实重算，入场窗外由 Portfolio 的同一时效语义禁止新增风险并明确选择现金、保持或减仓。禁止在编排层因 `valid_until` 过期直接抛弃整个资本处置；否则既会掩盖系统造成的错失机会，也会让资本覆盖率和后续评价缺少终态。该恢复不补跑历史 AI、不回写 Forecast，也不建立额外失败状态机。

每个获准进入资本链的稳定经济 `cause_id`，只要已经产生至少一份可资本化终态 Forecast，就必须让该组合 cause 最终得到且仅得到一份资本处置回执。消费唯一键是 `(portfolio_id, cause_id)`，跨重试、投递批次、Release 和资本行为版本保持稳定；`capital_behavior_id` 记录实际完成处置的行为并用于评价归因，但不能进入唯一键或让新版本重新消费旧机会。Forecast、单个 product projection、PortfolioTarget 或 Risk/Execution 中间事实都不等于这项义务已经完成；任一层失败后复用原身份和已冻结事实幂等补齐。恢复时只要当前 Mandate、行为合同、账户和点时产品事实仍足以完成同一 Portfolio 评价，就按当前时点形成现金、保持、减仓或仍合法的新风险目标；入场窗过期只禁止新增风险，不使整个资本决策不可用。只有权威依赖缺失、身份冲突或现役合同已无法重建完整评价时，才保存明确的 `DECISION_UNAVAILABLE` 处置及首个失败层、输入引用和原因，不能补做回看交易或伪装成主动资本选择。无需为此建立第二套状态机：开放义务由“该 cause 已存在可资本化 Forecast 且该组合尚无 CapitalCycleRecord”直接派生，健康状态报告最老开放义务和最近失败，后续无关批次成功不能将其清除。部分 projection 可继续用于各自实现诊断，但没有完整 PortfolioTarget 的批次不得进入产品选择或总资本效果评价。

账户快照是 Execution 从订单、成交、资金流水、持仓和点时估值投影出的组合事实，不是 Forecast 或 Portfolio 决策周期的所有物。`PortfolioTarget` 必须引用与自身 `portfolio_id`、`as_of` 一致的账户快照 ID 和内容哈希，但二者的 `cycle_id` 不得被强制相同：前者标识投资判断，后者只标识账户投影原因。没有新增账户因果事实时，同一组合、同一 `as_of` 复用最新快照；同一时间点发生执行或对账则以更高 revision 形成新快照，后续决策必须读取该账本头。恢复旧 Forecast 时按当前决策时点取得新的或既有账户事实，绝不改写旧快照、伪造重复 revision，也不因历史投影身份阻断当前 Portfolio 终态。

### 4.5 评价与权限

Evaluation 只服务两类裁决，不形成新的运行阶段。第一类是完整资本政策在同一 Mandate、风险预算和同期可投资事实下，相对 Reference Policy 是否值得获得、保留或扩大资本；第二类是 WorldModel、Forecast 来源、触发政策、Portfolio 算法等可选组件是否提供可辨识的边际价值，因而应保留、替换还是删除。前者决定资本权限，后者负责归因和压缩复杂度。数据、账户、风险与执行不变量属于 Release 硬验收，不因短期盈利而放宽，也不包装成另一层 Alpha 评分。

完整资本政策胜出不能证明其中每个组件都有效；某组件评分改善也不能证明整条政策值得交易。若总政策有效而某复杂组件没有边际贡献，应以不含该组件的更简单政策重新竞争并删除冗余；只有要声称“WorldModel 帮助了盈利”时，才必须同时具备同槽 Quant 对照、AI+Quant Forecast 改善和费用后资本增量的贯通证据。这一关系是因果归因，不是要求所有实验按四道串行门禁逐层排队。

总组合的主资本基准只有一个事前冻结、可实际执行且与 mandate 风险包络匹配的简单 Reference Policy；现金是生存与机会成本比较，不是另一个可随结果替换的主基准。Reference Policy 必须用当时合法 Instrument、真实现金流和同一账户约束机械推进，只有显式新实验才能改变。单一产品的被动持有只用于该产品实验的归因，不得出现在总账户主视图中冒充资产管理基准。这样既能判断账户是否真正增加财富，也能区分主动管理增量与被动承担 BTC、股票或其他 beta 的结果。

Reference Policy 的构造本身必须简单、透明且不使用主动 WorldModel：它先把 Instrument 映射到非重复经济风险，再以 mandate 的时域、流动性和总风险边界事前指定一个中性目标暴露，并以冻结暴露带再平衡。固定暴露、风险平衡、最小方差等可以在设计阶段帮助资产所有者形成候选，但同一计划只登记一个候选，后续历史评价只有否决权，不能在看完多个结果后挑一个“赢家”。如果资产所有者要改用另一种中性风险设定，必须建立新计划并重新积累独立证据，不能复用已揭盲结果。Mandate 的允许暴露是法律与所有者边界，不是必须凑齐的资产清单；最终 Reference 可以稀疏，但必须由共同压力情景、风险贡献和费用后购买力结果证明与总风险匹配，不能用产品数量或人工 `eligible` 标签自证。它不能随最新 AI 观点或近期表现变化，否则既失去基准含义，也与实际 Portfolio 重叠。

Reference 资格只由一份不可变选择制品授予。制品同时冻结两层不同证据：经济暴露层使用足够覆盖周期与压力状态的点时代理历史，回答该风险来源长期如何表现；实现产品层使用真实合约规则、可成交报价、交易时段、fee、spread、slippage、funding、basis、分红或其他现金流和场所事件，回答该暴露能否由当前 Instrument 忠实持有。新上市衍生品可以借更长的底层历史估计经济风险，但不得把底层历史冒充该合约自己的 funding、basis、流动性或规则历史。产品证据的最小数量与覆盖必须由现金流频率、交易时段、需要覆盖的状态和未建模误差对总风险的上限推导，不把“两年”或任一统一天数当成跨产品真理。规则、结算或可恢复执行缺失时直接拒绝；只是历史较短时，可在既有 Mock 试验权限内积累真实实现证据，但只有将未知性缓冲、不利 funding/basis 和流动性压力一并计入后仍满足 Mandate，才能登记 Reference。任一层无法给出这种边界时只保留候选状态。

资金费率历史只保存交易所实际发布的结算现金流，不按名义结算间隔补值。官方校验月档与 REST 在同一请求窗口逐条一致时，缺少某个预期时间戳表示该时刻没有官方结算；评价按零笔现金流推进并保留前后真实间隔。只有单一来源无法区分真实停结与采集缺失时才拒绝该窗口，不能以连续性门禁把交易所事实丢弃，也不能插值制造收益或成本。

经济代理还必须明确数据版本语义。为“现在开始生效”的静态 Reference 选择，可以使用采集时冻结的当前版本长历史估计无条件风险，但它只能支持该采集时点之后的政策选择，不能声称重建了过去每个日期当时可见的数据，更不能评价历史择时能力。数据源后续修订产生新的内容寻址数据集；除非启动新的预登记选择实验并重新通过盲测，否则不能改写已经冻结的 Reference。权益代理必须包含总回报，价格指数不能因历史更长而忽略股息；经济代理与真实实现产品的现金流仍分层结算。

选择计划在运行 evaluator 前以内容身份冻结：唯一候选、经济代理、开发/盲测半开区间、产品证据的最小数量与时间覆盖、完整成本版本、共同压力窗口以及购买力、回撤、压力、换手、成本和风险贡献阈值。评价只接受已经存在于 Git 祖先提交且当前字节未变化的计划；结果同时绑定该登记提交、登记时间、计划哈希和 evaluator 提交，不能依赖文件内自报时间事后补登记。当前版本的长期经济代理必须固定到准确数据集哈希；仍在增长的产品 K 线、双边报价、funding 和规则证据则冻结作用域与最低覆盖，评价制品再绑定实际命中的唯一数据集。拒绝记录只能产生不可变 `REJECTED`：它同时保存已可计算的经济失败和产品证据缺口；只有两者都无拒绝理由时才必须进入独立费用后 evaluator，不能由准备度检查直接授予资格。结果及其实际命中的源 Manifest 进入受跟踪证据目录；Manifest 保存原始来源、原文件或观测哈希和采集时间，原始大数据仍由内容寻址数据目录拥有，不复制进 Git。结果保存开发、盲测、逐个压力窗口、费用后购买力、换手、回撤和风险贡献，并只登记一个合格版本。发布时 Release 不仅校验文件哈希，还必须解析制品，确认其计划内容、证据层、状态、唯一候选、目标暴露和再平衡带与配置完全一致；被拒绝、缺证据或只同名的文件不能授予资格。Reference allocation 的 `target_exposure_fraction` 表达经济暴露比例，经济现金可以作为显式剩余项使其合计为一；编译后的产品名义、账本现金、抵押和可用流动性是不同投影，不能再要求彼此合计为一。其反事实账户随后复用正式账户的点时估值、产品现金流、取整和成本语义机械推进；只有暴露带被成本后的风险偏离突破才再平衡，不按月、固定日期或 AI 观点变化交易。若候选被拒绝，`Reference Policy` 保持为空，总组合主实验明确未启动；现役单产品组件实验可以继续，但不得宣称已经具备总账户资产管理或相对主动增值证据。

在登记候选前，必须先用预先冻结的开发段判断“当前合法产品集 × Mandate”是否存在基本可行域。这一诊断只搜索事前限定的简单、稀疏、无杠杆配置族，只有否决权，不能从历史最优权重生成 Reference。若整个简单族都无法同时满足购买力和风险边界，必须明确判定结构不可行，停止调权重和揭盲；后续只能分开处理两种真实变更：引入有完整规则、收益、流动性和执行证据的防御性收益/利率暴露，或由资产所有者修订 Mandate。不得把零收益稳定币伪装成无风险利率，也不得降低证据门槛、用已揭盲结果重选权重或为填补这一缺口创建第二套资本链。

Reference 候选还必须在增长、通胀、通缩、流动性紧缩和相关性反转等共同压力下说明每项暴露的经济职责，并检查风险贡献而不是只看名义资金比例。这吸收了“不同经济状态需要不同收益来源”的有效原则，但这些状态不是固定且完备的四格分类，资产也不因此机械等权；黄金、长久期利率、权益或现金是否保留，取决于当前 mandate、产品成本、相关结构和样本外压力结果。任何固定四等分、固定再平衡阈值或单一国家历史都只能作为简单压力基线，不能因其易解释就直接获得资本资格。

资本结果至少按三层归因：Reference Policy 自身的市场风险溢价、Forecast/Portfolio 带来的主动偏离、Risk/Execution/成本造成的保留或损耗。主结论读取同一 Mandate、同一外部现金流和同期可投资事实下，相对冻结 Reference Policy 的费用后增值及其跟踪风险、回撤和尾部结果；不能在看到结果后对任一路径缩放波动、替换基准或删去现金期来制造“同风险”胜出。绝对 PnL、相对现金、单资产被动暴露和 Forecast 分数作为互补诊断，不能选择表现最好的一条事后改名为基准。

长期资本有效必须同时满足绝对与相对条件：在目标时域内费用后复利为正、回撤和尾部风险不超过 mandate，并相对 Reference Policy 产生与主动风险相称的可靠增值。仅仅“比下跌的 BTC 少亏”、跑赢现金但承担不成比例的尾部风险、或依靠 Reference Policy beta 获利，都不能证明主动世界认知与资本决策有效。记账本位存在显著购买力或信用变化时，评价另报真实购买力和结算资产风险，不能把名义 USDT 不变当成资本保全。

每项实验在结果发生前冻结输入、行为身份、成本、基线、评价方法、样本边界和停止条件。评价读取所有预登记样本，包括无预测、未交易和失败样本。结果只能改变未来 Release 或权限，不能选择性改写历史。

评价必须把四个互不替代的问题分开。Forecast proper score 判断概率分布是否优于同合同的简单基线；Product residual 判断从规范标的到具体 Spot/Perpetual 的 basis、funding 与规则映射是否准确；Capital choice 使用当时已冻结的全部合法候选、目标金额和完整未来成本，在共同终点按经济暴露比较“当时选择的产品或现金”与“事后最佳合法产品”的单位净收益，只诊断捕获、错误入场或错过的方向；Execution/Account 才评价实际订单、成交、持仓和费用后的资金结果。只有本轮新产生 Forecast 并完成完整候选比较的 Capital Target 可以进入跨经济暴露评价；只覆盖当前持仓的程序化风险复核、重复消费既有 Forecast 或只减险动作不具备声称“没有错过其他机会”的信息范围。产品 Outcome 从原始投影锚点结算，Capital choice 必须先用冻结的决策毛收益与投影毛收益之差把它重锚到真实决策时点，再扣决策时冻结的未来成本，禁止把决策发生前的行情归功或归罪于该选择。Capital choice 的事后最佳产品不是可投资基准、交易策略或授权依据，不能据此追涨、回填订单或降低未来门槛；它只负责让“没有下单”也能区分正确持币与错过成本后机会。四层都读取不可变点时事实，任何一层不得用另一层的好结果掩盖自身失败。

永续产品的退出 basis、funding 和映射不确定性不是 Forecast 的一部分，也不能以常数假设隐式获得 Alpha。每条 basis 演化规则必须拥有独立版本和来源明确的点时证据，并与“不收敛、维持当前 basis”的最简单基线竞争；历史缺少可执行双边报价时只能否决，不能授权资本。费用后账户还必须把参考标的价格收益、basis 变化、funding、bid/ask、滑点和手续费分别归因。一次交易即使最终盈利，只要方向收益主要来自 Forecast 未预期的价格变化，就不能把全部盈利记为方向模型能力；同样，方向预测错误也不能抹掉可独立复现的产品映射增量。

当前 PAXG 4h 全基差收敛候选已按预登记计划在 2025-04 至 2026-08 的 2,334 个验证截面上被否决：其退出基差 MAE 为 4.55bp，劣于基差持久基线的 1.34bp，四个验证阶段均未胜出，盲测因此未开启。现役 BTC/PAXG 永续映射只携带资本决策时可见的现货—永续 mid basis 到经济终点，不把收敛制造成 Alpha；旧映射投影仍不可变结算，但同一源 Forecast 不得被新 cohort 回写。预登记计划与不可变结果是唯一保留的研究证据，一次性验证代码在结论进入现役映射后删除。

#### 4.5.1 Quant prior 与唯一资本来源

ForecastContract 是来源无关的经济问题，DecisionSlot 和 Outcome 也只各存在一份；不同生产者只有在独立假设通过预注册验证并发布后，才可通过各自不可变的 ProducerBinding 对同一槽承担应答义务。当前现役生产者只有 BTC/PAXG 72 小时滚动无条件 prior 与读取同槽 WorldModel 的 posterior，两者均为 `RESEARCH`，共享合同、槽和 Outcome，只在 Evaluation 中比较；已失败的纯 Context、4h Quant 与4h posterior 只保留不可变历史和研究制品，不再创建义务或调用。任一经济问题在同一时点最多只有一个 `CAPITAL_CANDIDATE` 生产者，其余研究 Forecast 永不投票、合并正式目标或进入 Venue 账户。更换正式来源只能发布新的前瞻行为和资本授权，不能由运行时比较当轮输出后挑赢家。

Quant prior 是 Forecast 内部的冻结概率输入，不是新的业务阶段。最小 prior 可以像现役行为一样，只由内容寻址基线制品、截止前已结算 Outcome 和滚动更新规则确定；没有主动因子模型时，模型可见输入只包含最终概率、bucket 与预期毛收益，不能伪造因子值、regime、可靠性或候选分歧。未来主动 Quant 只有在样本外胜出并发布后，才为同一接口增加本槽点时因子、程序适用状态、可靠性和分歧摘要；完整候选、训练数据身份、严格截止、缺失规则、参数和校准仍留在审计制品，不把落选概率表、原始 K 线、逐笔或训练样本发送给 AI。模型可见投影永远只是当前实际 prior 的充分统计，不是预建的通用面板。制品、特征、投影合同或选择规则变化必须产生新的 producer behavior，历史 Forecast 与 Outcome 不重写；任何 proper score 改善本身都不得被解释为费用后 Alpha。

初始 Quant 实验从一个简单、透明、可完全回放的指定模型和少量有经济含义的因子开始；momentum、mean reversion、carry、breakout、volatility 与 liquidity 只有在当前目标、时域和数据点时语义完整时才进入候选。经典的[时间序列动量](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2089463)、[跨资产 carry](https://www.nber.org/papers/w19325)、[HAR-RV 波动率](https://academic.oup.com/jfec/article-abstract/7/2/174/856522)及 [crypto carry](https://www.bis.org/publ/work1087.htm)研究只提供可解释先验；其资产、持有期、实现产品和成本与本项目不同时，不能直接获得运行资格。RSI、MACD、布林带等由同一价格历史变换出的名称也不构成独立信息，只有在同口径样本外结果中相对已有因子提供增量，才作为一个新候选进入搜索历史。开发、验证和盲测按时间顺序冻结，所有搜索过的候选和失败结果计入选择历史；不得因为复杂模型历史拟合更好就默认组合或上线。常规市场状态识别、模型适用度和候选权重必须由冻结程序根据点时数据确定，AI 不得在每次调用中离散选择或启停算法；否则同一输入的生成波动会被伪装成择时能力，并直接制造换手。指定 prior 可以是经盲测胜出的单模型，也可以是稀疏、稳定且可解释的条件混合，但二者必须作为同一种 Quant 制品接受样本外竞争，而不是并存为两套决策链。某目标缺少合格点时输出 `NO_ESTIMATE`，不得用静态概率、其他产品 K 线或当前已知未来补齐成伪 Quant 预测。

Quant 候选只允许使用“点时 Market/State → 经济语义正交专家 → ForecastContract 统一概率桶 → 冻结状态混合 prior”这一条程序链，不另建买卖分数、策略投票或评价账本。2026-08-29 完成的唯一 72 小时候选以 BTC/PAXG 日线为点时输入，冻结趋势延续、标准化反转与 HAR-RV 波动三个专家；两种资产上的全部专家在 selection 有序概率分数均劣于同槽滚动无条件分布，因此 validation 与 held-out 均未读取，候选永久拒绝且资本权限不变。一次性 evaluator、CLI 和专属测试已经删除，只保留预登记计划、不可变结果及提交历史。现役 prior 继续使用共享 ForecastContract 下的滚动无条件分布；仓库当前不存在状态混合 producer，也不把“架构已经实现”误写成“模型已有增量”。未来独立信息只有先以新的预登记假设严格优于该基线，才允许复用同一 Contract 进入前瞻 `RESEARCH`，不得围绕已揭示区间搜索相邻窗口、状态边界、权重或专家组合。

当 Forecast 时域长于采样间隔时，重叠样本可以用于拟合，但不能冒充独立验证证据。开发、验证和盲测边界必须按完整 Outcome 时域 purge；从样本分布推导的 bucket 边界、代表值和基准也只能使用开发带，否则验证/盲测分布已通过标签定义泄漏给模型。有序收益桶使用距离敏感的 ranked proper score 作为候选主排序，同时报告 Brier/校准、预期 bps 对真实连续 bps 的幅度误差与单调性；候选必须先在全部事前固定的非重叠时间相位上优于简单基准，再按最差相位 ranked score 找到最佳候选，并在该最佳候选四个非重叠相位得分的一标准误差带内选择事前排序最简单的候选。标准误差、候选顺序和入选带必须写入同一冻结制品，不能另设主观容差；这避免不可识别的微小分差把搜索噪声变成模型复杂度。不建立把分数、费用和 PnL 随意加权的综合指标：Forecast 门只否决没有分布增量的因子，唯一下游逻辑账户再独立回答费用后是否值得资本。不得挑表现最好的相位、把重叠行数当成样本量，或用全样本平均值掩盖只在某个时间锚点成立的复杂度。盲测只评价预先选定的唯一候选，揭盲后不得换模型；未来部署可以用训练截止前的全部数据重估已选结构，但该次盲测只能作为历史诊断，真实权限仍只读取后续前瞻结果。

Quant 候选在验证段选定且盲测一次性揭示后，先接受无须估计的成本下界淘汰：若冻结模型所有可达状态的预期毛收益都不超过合法产品确定性的开平仓手续费下界，则点差、滑点和不利 funding 只会使结果更差，该 producer 立即退出在线研究，不再等待盘口数据或前瞻样本。跨过成本下界后，才接受一条仅有否决权的历史资本可行性诊断：把这一个冻结候选按原定 cadence 顺序映射到当时合法产品，并复用正式 Product、Portfolio、数量取整、funding、手续费、点差与滑点语义推进同一初始账户，报告净收益、换手、费用、持有期、回撤以及相对现金和适用 Reference 的结果。该诊断不能反过来搜索入场阈值、持有期、仓位、产品或成本参数，也不能因为历史盈利授予资本；但若其预测幅度明显无法覆盖完整成本，或相邻输出翻转使全部毛收益被换手吞噬，就不应再浪费真实前瞻调用验证同一假设。历史可执行报价、产品规则、funding 或交易时段不具备点时完整性时必须明确输出 `UNAVAILABLE`，不得用收盘价、当前规则或主观固定滑点拼成伪实盘结果；这种候选至多保留离线 Forecast 假设，不自动获得在线运行资格。该诊断是同一 Quant 研究制品的只读投影，不新增第二套 Portfolio、账户账本、调度或运行服务。当前 BTC 4h Quant 的最强状态仅有 6.50bp 预期毛收益，PAXG 仅有 2.65bp，均低于 10bp 确定性往返手续费下界，因此已停止在线 producer；其轻微 proper-score 改善不再被误称为可交易 Alpha。

独立预登记的 BTC 12 周方向符号候选也已完成一次回顾性否决：2020-03 至 2026-08 使用真实逐次 funding、5bp 单边手续费和 2.5bp 单边摩擦后，全期净复合收益虽为正，但最大回撤为 69.70%，四个固定阶段只有前两个为正，2023 年后的两个阶段均亏损，因而按原规则拒绝且不进入前向研究。计划与结果永久保留以阻止重复搜索；一次性 evaluator、CLI 和测试已删除。这个结果说明“降低频率”能减少手续费，却不会自动产生跨状态稳定 Alpha；下一候选必须带来独立信息或更明确的经济风险来源，不能围绕已揭示历史继续搜索相邻 lookback、周锚点、过滤阈值或仓位变体。

BTC 现货多头与固定到期季度合约空头的 30 日现金套利也已按单一预登记规则否决：18 个官方交割合约中 13 个数据完整、10 个越过 40bp 完整成本门，账户累计净收益为 2.10%、最大回撤为 4.13%，但入场合约仅 70% 为正且四个固定阶段只有两个为正。保证金缓冲不是失败原因，收益跨时期不稳定才是。该结果不得用于搜索相邻到期天数、基差阈值、仓位或退出规则；计划与不可变结果保留，一次性评价实现已删除，候选不进入模拟盘。

BTC 现货多头与 USD-M 永续空头的市场中性 funding carry 同样已按唯一预登记规则完成盲测：过去 30 日已结算 funding 只有严格越过两腿 40bp 完整往返成本才进入随后 30 日，单腿只使用账户权益 25%，现货盈利不跨钱包补充永续保证金。development 成本后为 +11.57%，validation 为 +2.60% 且通过全部门槛，但 2025-01 至 2026-08 的一次性 blind 为 -0.14%；8 个入场窗只有 37.5% 为正，62.89 USDT funding 收入不足以覆盖 76.08 USDT 成本，四个子阶段只有一个微正。没有强平且基差损益接近零，说明失败来自 funding 持续性消失和成本，而非方向或保证金。该候选永久拒绝，不得搜索相邻 formation、持有期、成本门或仓位；计划和结果保留，一次性评价器、CLI 与测试删除。

可投资域配置是经过验收的权限输出，不是产品发现来源。交易场所新增、移除或实质修改产品时，Market 应从官方完整 Spot/Derivative 产品目录保存一份内容寻址快照并只对目录差异形成产品评价义务；未变化目录不唤醒 AI，新产品也不自动进入 Universe、Forecast 或订单。一个已被明确选中的候选可以进入 Market 的公开只读观测集合，以复用现有行情事实和报价冻结器积累产品证据；它仍不得进入 Mandate 分析资产、材料触发、Forecast、Portfolio、Risk allowlist、Planner 或 Execution spec。报价取证读取 Market 已拥有的产品身份，不能反过来要求候选先获得 Capital 执行资格，否则会形成“先有产品证据才能准入、先准入才能采集证据”的循环。候选只有能够降低当前已知产品缺口，且通过账户资格、法律与结算语义、公司行动、费用、深度、跟踪和压力退出评价时，才产生新的未来 Universe 版本。2026-07 新增的 `SPYBUSDT`（SPYB bStocks Spot）证明静态配置会漏掉重要替代表达：它从结构上消除了 SPY 永续的 funding 与强平，但只是 ADGM 发行的证券凭证，具有资格、发行人、溢折价、multiplier、税费和暂停风险，且截至 2026-08-29 只有 53 根完整日线。它已被选为产品映射研究候选，不进入现役可投资域或 Reference。

产品跟踪不能用低频、不同步的底层收盘价估算，否则正常价格变化会被误记为映射误差。Binance 为 Spot 提供带交易所时间的 `referencePrice` 流；`SPYBUSDT` 的计算类型为 `EXTERNAL`、method 2，官方定义为对应 USDⓈ-M Futures 的 index price。Market 因此只为已选中的候选在既有 WebSocket 连接内追加该官方流，并把 ReferencePrice 作为独立不可变事实保存；它不是行情触发、AI 输入或估值价格。唯一产品映射 evaluator 按首次可见时间将 SPYB 双边可成交报价与同 symbol ReferencePrice 点时对齐，冻结 spread、买入溢价、卖出折价、顶部深度、时间偏差和覆盖率。没有对齐参考事实的报价只计入缺失覆盖，不用最近值或两分钟 Perpetual 状态补齐。该 evaluator 只回答产品能否忠实表达经济暴露，不产生 Forecast、目标仓位或订单；验证完成后若候选被拒绝，应停止专属 referencePrice 订阅，但保留事实与结果。

Binance 同账户现金收益可行性已经完成一次只读核验：USDT Flexible 与 RWUSD 均具备账户资格和足够当前 Mock 规模的额度。USDT Flexible 的正常赎回被产品说明描述为即时，但同一说明也明确集中赎回、极端波动与平台流动性不足可导致延迟；API 的 `canRedeem` 和请求受理均不等于赎回历史终态 `PAID`，也没有最坏到账上界。Flexible 资产可自动赎回用于 Spot/Convert，不能据此假定它可作为当前永续产品的即时保证金。RWUSD 又以 USDC 赎回，额外引入结算资产转换，因此不属于当前 USDT 现金实现的等价候选。

现金产品可行性与方向 Alpha 独立：没有合格 Forecast 不能阻止 Reference 的现金实现被评价，否则会形成“先有 Reference 才能评价 Alpha、先有 Alpha 才能实现 Reference”的循环依赖。Portfolio 先给出经济现金目标，Risk 依据当时保证金、未结现金流、待执行义务、提款和压力平仓成本计算可立即动用的运营现金；只有剩余部分可成为收益型现金。收益产品本金和已确认奖励可以按明确估值与折扣计入 NAV，但在赎回终态确认前对可用流动性的贡献恒为零。机会成本由同一 Reference 的再平衡义务及当时合法候选仓位计算，不以是否已经发现 Alpha 为前提。

当前冻结结论仍为 `DEFER_RUNTIME_ADMISSION`，但“等待合格 Alpha”不再是重评条件。真正未闭合的是 USDT Flexible 的申购、奖励计提、赎回终态、估值折扣、账户对账和压力情形；在这些语义通过预登记产品评价前，不改变 Reference、不产生真实或模拟申购。此前资本周期中的低频 APR/额度探针没有任何 Portfolio、Risk 或 Execution 消费者，却同步拖慢权威交易路径，因此移除；既有不可变产品事实继续作为研究证据。若重启候选，只能在现有产品评价家族中以 USDT Flexible 的一个最小生命周期纵切片完成，复用唯一账户与资本决策，不建立轮询器、现金专属决策器或第二套账户状态机。现金收益只改善现金实现，永远不能报告为方向 Alpha。

生命周期 v2 评价进一步确认：申购、奖励、赎回与未知终态可以被纯事实投影为同一账户会计，但当前 Reference 为空，Portfolio 也没有自由现金与收益现金之间的目标语义，因此该投影没有合法消费者；继续增加存储、命令或 Mock Venue 会先形成一条无权威来源的产品旁路。结果据此为 `INCONCLUSIVE`，试验实现已删除。Reference 先以自由 USDT 表达经济现金并完成自身产品可行性；只有同一 Portfolio 已能产生可回放的现金实现目标后，USDT Flexible 才能作为该目标的实现 challenger 重新进入评价。

经济现金不得继续按永久零收益建模，也不得把当前交易场所 APR 倒填进长期历史。独立预登记的一月期美国国库券总收益代理使 15% 黄金、15% 美国权益、70% 经济现金候选在 1960–2015 开发段取得 2.46% 实际年化和 7.08% 最大回撤，在 2016–2025 盲测段取得 2.98% 实际年化和 4.91% 最大回撤，四个固定压力窗口最差损失 7.44%，经济层全部通过原门槛。但 Binance USDT Flexible 的 18,719 条连续小时 APR 在 780 天内实现年化约 2.72%，与国库券代理重叠日平均少 1.95 个百分点且只有 9.1% 的日期更高，因此它不是可执行短债，也不能直接继承经济代理结果。第一条前瞻同账户事实已证明当前 APR、额度与普通操作可用，但不能补齐压力流动性；冻结准入结果为 `DEFER_RUNTIME_ADMISSION`。既有只读观察作为不可变研究证据保留，权威资本路径不再持续采集无消费者事实；产品生命周期、压力赎回和机会成本评价通过前不登记 Reference、不接入权威资本。

预测时域本身属于 ForecastContract 和研究假设，不能由 AI 或运行时在看到当轮行情后选择。候选时域必须同时来自因子的原生经济持续期、可获得的独立样本和现实往返成本；当前合同时域的预测幅度长期小于成本时，应停止或另行预登记更匹配的合同，而不是事后提高入场阈值、延长持仓或搜索相邻周期。时域研究一次只揭示事前指定的目标、特征窗口和一个候选终点，并把不同 UTC 锚点分别视为相关稳健性切片；历史通过仍只允许建立新的前瞻研究行为，不能把较长时域的回测收益直接授予现役 4 小时生产者。

Quant prior 的研究资格与资本 Alpha 资格是两个不同问题。prior 首先是一份不读取 WorldModel、点时可重建且与 ForecastContract 同时域的统计分布；最简单的滚动无条件分布本身就可以承担这一对照，只要其样本、可见时间、更新规则和校准误差完整冻结。技术或资金流模型若不能优于它，就删除该模型而回到简单 prior，不能因此阻止检验 WorldModel 是否相对简单 prior 增加信息。反过来，prior 或 posterior 的 proper score 改善都不构成资本资格：只有对应完整政策在相同产品、延迟、成本和风险下产生费用后增量，才允许进入 Portfolio。这样既不要求传统 Quant 在 AI 实验开始前已经解决盈利问题，也不把一个诚实但无 Alpha 的基准误写成可交易策略。

Posterior 行为读取同截止 WorldModel 和当前实际 prior，并输出唯一 posterior。现役滚动无条件 prior 没有主动因子、模型适用度或候选分歧，输入因此只公开合同分布与预期毛收益；未来若主动 Quant 胜出，才在相同行为合同中紧凑增加其真实点时因子、可靠性与分歧摘要，不能把离线落选候选交给 AI 隐式择模。凡能从行情、主动流、OI、funding、仓位、basis 或跨资产价格状态重复计算的方向信息，都必须先成为点时可回测的 Quant 候选并经程序筛选；尚未进入 prior 的技术状态只能验证外部机制是否正在传导，不能由 AI 临场解释成第二套技术信号。WorldModel 中完全由这类市场状态构成的机制只保留认知与验证价值，不得实质改变 posterior。AI 只能依据有时间边界、并至少由一项非市场状态事实或事件支撑的政策、资金流、制度变化和跨域因果机制修正最终 bucket，不能改模型权重、点名启停算法或再建立一套 regime 分类。输出必须逐 bucket 说明相对 prior 的概率变化，并把每次实质偏离绑定到该结构证据、竞争解释和反向证据；没有结构增量时原样保持 prior。AI 不重新计算因子、收益、波动、成本、仓位或订单；产品 break-even、预测延迟和完整未来成本只由后续统一 Product/Portfolio 与资本评价计算一次。

研究期 challenger 不能成为正式资金链前的第二条交易路径。现役 posterior 已按最小纵向切片运行：同一 DecisionSlot 和 information cutoff、唯一冻结输入、既有 Assessment Worker、公共 Forecast/Outcome 账本及明确 `NO_ESTIMATE`；它直接绑定合同、WorldModel、prior、Prompt、Schema 和 Codex 行为身份，不恢复纯 Context 前置调用、稳定性常驻副本或第二套结果系统。每个已到期 Forecast 槽本身就是一次显式、可审计的同点时 WorldModel 复核原因；即使该截止点没有新的材料 Delta，也必须据此形成 DecisionPacket，不能把材料变化门槛误用为 cadence 后验的输入门槛。研究调用不能阻塞 Trigger、行情、结算和账户对账；同一时点不能保留两个获授权生产者并行投票。未来新假设仍必须先以离线点时数据否决泄漏或不可行管线，再建立新的独立前瞻行为；历史重放只能验证管线，不能证明 AI Alpha。

前瞻研究的长期对照只有两种方法：不读取 WorldModel 的透明 prior 与 AI + prior posterior；冻结的现有 Context 行为仅作为历史参照，不扩建为第三套长期架构。它们共享槽、信息截止、完成后 Outcome 起点、bucket、缺失语义和评分；分别报告覆盖、proper score、校准、预测幅度与真实收益的单调性、同输入离散度，以及把相同预测映射到当时合法产品后的费用后资本反事实。样本数量只描述不确定性，不构成固定交易门槛。若一个主动 Quant 模型不能优于滚动无条件/简单市场基线，删除该模型假设并让简单基线继续承担 prior；若 AI posterior 不能相对同槽 prior 提供前瞻增量，删除 posterior 复杂度；只有通过完整费用后资本评价的唯一行为才进入正式 Portfolio。

生产者之间的增量只能在同一 `DecisionSlot`、同一已结算 Outcome 且双方都给出概率分布的交集上配对计算，不能拿各自覆盖不同资产、事件来源或时期的平均分直接相减。配对报告同时保留各自全部义务的 Forecast、`NO_ESTIMATE` 与覆盖率，使低覆盖不能靠缩小交集获得好成绩；无论单生产者评分还是生产者配对，同一联合调用的多个目标都先在时点内等权聚合，再按不重叠时间区间计算点估计与不确定性，连续收益误差和相关性也遵守同一面板口径，不能把相关资产数量冒充独立样本。资产级 Forecast 与 Outcome 仍分别永久保留，面板只是现有账本的只读统计投影，不新增结果表、Worker、调度或晋升门槛。

概率配对只回答“谁更接近结果”，不能证明谁能赚钱。费用后生产者对照必须从同一冻结初始账户出发，为每个被比较的 producer behavior 各推进一条由 Evaluation 域拥有的逻辑账户路径：它们共享 Mandate、可投资域、Portfolio、Risk、Execution、产品规则和成本语义，但分别按自身实际 `available_at`、`NO_ESTIMATE`、前序目标与持仓消费 Forecast；任何路径都不得借用正式路径的 Target、仓位、产品投影或成交。Forecast 及其经济预期不得读取本次信息截止后的事实，但资本重放必须使用该生产者实际可用时点的可成交报价、产品规则和随后现金流，否则会抹掉真实延迟成本。逻辑账户只从这些公共点时行情和产品事实确定性重建目标、模拟可成交订单、funding、费用与终点权益，不写真实 Venue，也不建立第二套业务账本、调度或 AI 调用。每次对照在共同评价终点必须把仍开放的仓位经同一 Portfolio、Risk、Planner 和 Mock 成交语义强制清算到现金，按终点可执行方向报价扣除真实退出手续费并纳入换手；只按 bid/ask 估值却保留仓位会漏掉退出费，严禁称为完整成本。若产品最小数量、报价或规则使清算无法完整执行，本次资本证据必须明确不可用，不能用中间估值冒充终态。其内容寻址评价制品保存输入身份和完整轨迹，必要时可从公共事实重放。同槽 `posterior == prior` 而资本动作不同，只能归因于生成延迟及其后的执行价格，不能算作 AI 信息增量；同截止点概率配对与实际延迟账户已经分别回答信息价值和完整行为价值，不再复制一条“延迟 Quant”账户。最终同时报告净权益、回撤、尾部损失、换手、费用和相对同风险现金/Reference 的增值，并将差异归因到 Forecast、产品映射、资本选择或执行。单槽目标重放只能诊断某次选择，不能累加后冒充这条路径的费用后业绩；proper score、一次盈利或正式模拟账户的结果也都不能替代该对照。

同输入稳定性副本也必须遵守这条边界：正式输出与每个副本各自从同一冻结初始账户推进独立的只读逻辑路径，成功副本按自身实际完成时点取得可成交报价，失败副本按 `NO_ESTIMATE` 推进；随后比较现金选择、产品、方向、仓位、换手、费用和权益。该评价不能要求研究 producer 先取得 `CandidateCapitalAuthorization`，不能寻找或复用真实 `PortfolioTarget`，也不能把副本变成新的业务 Forecast 或资本投票。否则“晋升前必须证明资本稳定”和“只有晋升后才有可重放目标”会形成无法满足的循环条件。

运行幂等与模型稳定性是两件事。同一决策槽只保存一次权威 Forecast，重试不能更换交易结果；后续持仓复核只对这份不可变 Forecast 做程序化重估，不能再次询问 AI。但这仍不能证明生成模型对同一输入不敏感：候选行为必须在正式调用前登记精确输入副本义务；正式结果取得 AI 增量资本权限时，副本使用同一模型可见输入、Prompt、Schema、模型、推理强度和期限，分别审计概率分布与期望收益离散度。副本只形成稳定性事实，不增加 Forecast、Outcome、独立样本或投票权，也不进入实时资本链。

生成稳定性不是独立常驻子系统。若未来 AI challenger 的实际预测增量大到值得验证重复性，稳定性应作为该候选的一次性离线评价，复用冻结输入、公共 Forecast 事实和完整 Portfolio 点时重放；不得建立长期副本调度、结果表、Dashboard 面板或用多次采样投票制造 Alpha。生成噪声与费用后 Edge 同量级时，该候选直接失去资本资格。

因此一次结构合法的 AI 输出只是随机 Forecast 行为的一次样本，不是已经校准的确定性收益率。研究资本权限必须把这种行为作为整体评价，并把精确输入离散度纳入估计不确定性；稳定性不足时可以继续保存 Forecast、产品反事实和到期 Outcome，但不能把单次采样恰好越过零点解释为可靠 Edge。若未来用多副本聚合降低推理方差，副本数量、并发与失败规则、聚合函数和最终唯一 Forecast 身份必须共同构成一个新的预登记 producer behavior，完整组件输出只作审计；该行为仍须以真实前瞻、费用后资本结果证明增量，不能在下单前临时重问到“答案一致”为止。

WorldModel 的投资价值由同槽透明 prior 与 AI posterior 的前瞻差异识别：prior 只表达截止前已知的基础分布和已通过的程序化市场关系，posterior 只增加 WorldModel 所表达的结构变化。两者共享 State、合同、信息截止和 Outcome，posterior 的输入与输出在调用前持久化；逐资产配对结算，但一次联合调用只形成一个独立时间区间，不能把资产数冒充独立样本数。对照只进入 Evaluation 逻辑账户，不进入 Portfolio。Forecast 相对基线的均值改善只是点估计；资本权限还必须读取依赖结构、校准、覆盖率、完整搜索历史和多种市场状态下的成本后结果。若无法把增量归因于 WorldModel，而 posterior 只增加延迟或噪声，则删除 posterior 复杂度，不再增加第三条无 WorldModel 的 Codex 消融链。

Forecast 的采样政策也是行为的一部分。Cadence 是不依赖市场状态的覆盖义务；每个固定时点都必须保留独立的仅定时槽。材料来源回答“满足冻结条件时是否及时重估”，不能消费、提前履行或改写 cadence 义务；否则重大事件附近的固定样本会被选择性删除，既污染一般预测能力，也无法构造仅定时资本反事实。每个终态按仅定时或仅材料来源分层计算覆盖率、评分和不确定性；共同 Outcome 和重叠时域按预登记时间簇处理，不能把相关事件当成多个独立成功。

不存在覆盖所有问题的通用 `EvaluationPlan` 或 `EvaluationReport`。Release 验收、Reference 资格、Forecast 评分、Quant/AI+Quant 配对、Product residual、Capital choice 和账户结果分别由唯一领域 evaluator 定义最小类型化合同与结果；治理查询只从这些事实派生共同身份与引用，Dashboard、Agent 和权限不重算结论。跨 evaluator 的稳定评价家族、完整搜索历史、独立裁决和权限规则由 [`SELF_EVOLUTION_DESIGN.md`](SELF_EVOLUTION_DESIGN.md) 唯一规定，本文不再复制第二套学习协议。

任何实验资本资格必须引用对应问题的不可变类型化计划；任何正式权限必须继续引用适用的类型化结果、producer behavior、ForecastContract、mandate、Reference Policy 和 Release，并冻结作用域、资本包络、最大累计损失、有效期、退化条件与撤销动作。样本不足、计划到期或行为身份变化不得默认续权。安全硬约束可以直接减少风险，但不能借安全名义获得 Alpha 权限。

AI 历史重放可验证数据、Schema 和稳定性，但不能排除模型训练知识泄漏，因此 AI Alpha 和资本权限只由真实前瞻样本证明。任何“已实现”“运行健康”“文字更深”或少量模拟盈利都不等于稳定盈利。

Release 必须冻结所有会改变实际行为或用户所见事实的内容：代码、配置、Schema、Prompt/模型绑定、运行时外部制品和前端构建产物。进程从该提交的冻结 checkout 或内容寻址制品启动，不能从持续开发工作树或未登记的 `web/dist` 提供现役版本。切流 readiness 读取新 Release 自己的 Worker、调度、数据、账户和已启用生产者事实；事实尚未形成时显示 warming，不得用旧 Release 记录或“进程在线”冒充 ready，也不得为了 ready 伪造资本行动。唯一 supervisor 在整个生命周期持有单写者租约；READY 后子进程退出时先停止整组，再对上一兼容冻结 Release 做至多一次有界恢复并重新通过同一 readiness，恢复失败后保持离线可诊断状态，不以无限重启掩盖确定性故障。计划停止不触发回滚。

Release 的投资晋升裁决与本机切换是两个相邻但不重叠的职责：Governance 只产生已授权的完整 Manifest，唯一发布入口只机械执行该 Manifest，不再评价 Alpha、修改配置或选择候选。入口在旧版本仍运行时，从候选冻结 checkout 使用候选代码完成无写入预检：校验代码、配置、Schema 兼容性、制品和六个现役服务的真实装配；装配必须把构造与激活分开，不能为了预检创建 TriggerPlan、Forecast、账户或其他业务事实。预检不通过时旧版本完全不动。

切换窗口先从权威运行事实确认没有 active batch、非终态 ExecutionGroup，且账户能够从已对账快照恢复。随后由一个本机互斥租约保证任何时刻只有一组写进程：停止旧版本后按 Market/Information、Outcome/Trigger/Assessment 的依赖顺序启动候选，Dashboard 不参与写链并最后切换。候选只有在有界时间内同时证明进程仍存活、Temporal Worker 正在轮询候选任务队列、TriggerPlan 已绑定候选 Manifest、新 Market/Information 观测已经产生、账户恢复一致且已启用 Producer 可达时才 ready；历史健康记录、旧进程产生的事实和单纯端口在线不能代替这些条件。超时或任一进程退出时先完整停止候选，再用同一入口和原冻结参数恢复上一完整 Release；Schema 不兼容回滚时只能发布向前兼容的恢复版本，禁止自动 downgrade。每次预检、切换、ready、失败和回滚保存脱敏且内容寻址的运行回执，但不复制业务事实或建立第二份 Release 状态库。

AI 输入容量按最终模型可见投影校验：确定性 State、机制验证观测和上一轮认知写入后仍必须满足运行时上限。不可变 Packet 保持具名对象供审计，模型可见投影把同构资产状态无损编码为一份列合同加多行数值，不能靠重复字段名消耗注意力，也不能以摘要、截断或提高上限代替结构压缩。当前最小因果基线与直接触发 Evidence 必须同时存在；上一轮认知是待复核假设而非当前证据，不能成为删除某个唯一当前因果通道的理由。中间 Packet 预算可以指导去重和高密度投影，但不能替代验证观测写入后的最终容量不变量；运行时失败或生成一份因事件增多而丢失宏观、流动性、资金流基线的认知，都不得被用作正常的信息淘汰机制。发布测试必须覆盖最大合法资产矩阵、世界机制验证观测和直接事件同时存在的最终投影，而不只是验证前的空观测基线。

Release 是部署身份，Pipeline 是写入与协调语义，ProducerBehavior 是预测行为身份，三者不得互相代替。代码或界面发布在 Pipeline 语义未变时只把现有 TriggerPlan 递增 revision 重绑定到新 Manifest，保留同一 Temporal 协调器的 `last_analysis_at`、待处理事件和未来唤醒；只有写入/协调语义实际改变才切换 Pipeline。行为等价的 Release 也不得重置 Forecast cohort。

## 5. 领域所有权

| 领域 | 权威所有权 | 允许依赖的上游 |
|---|---|---|
| `market` | Instrument、报价、成交、K 线、funding、市场结构和交易规则观察 | 外部 Venue |
| `information` | 官方日历、原始文件、新闻和事件观察 | 外部来源 |
| `state` | Canonical Fact、确定性 State 及其 Evidence 引用 | market、information |
| `cognition` | WorldModel、认知行为和实际输入快照 | state |
| `forecast` | ForecastContract 的运行绑定、Forecast、结算标签和来源表现 | state、cognition、market |
| `portfolio` | 当前状态到目标组合的经济比较、PortfolioTarget | forecast、已对账账户、market |
| `risk` | 风险限额、压力、保证金约束和 RiskDecision | portfolio、已对账账户、market |
| `execution` | TradePlan、Venue 账户、订单、成交、持仓和 Reconciliation | risk、market |
| `governance` | Evaluation、实验登记、Release 和权限 | 所有领域的不可变结果 |
| `scheduling` | 事件合并、定时唤醒和主 Agent 触发计划 | 各领域的到期/变化通知 |
| `decision_cycle` | 一次闭环的幂等编排和阶段交接 | scheduling 与各业务用例 |
| `dashboard` | 权威事实的只读中文投影 | 各领域只读接口 |
| `research` | 点时回放、基线和隔离实验 | 生产纯逻辑与冻结制品 |

关键所有权裁决：

- State 只拥有可确定性重建的事实投影；Cognition 独占 WorldModel，因为因果解释可以被反驳但不能伪装成事实。Forecast 只引用二者的不可变身份。
- Execution 拥有交易场所账户事实；Portfolio 和 Risk 只读同一份已对账快照，不各算一份余额或持仓。
- Governance 拥有评价与权限，但不能直接写 WorldModel、Forecast、Target、RiskDecision 或订单。
- Decision Cycle 没有业务模型、策略、表和评价规则；若协调器开始裁决“该不该交易”，逻辑必须归还对应领域。

## 6. 触发、AI 与主 Agent

Scheduling 只表达“何时重新运行哪项用例”，触发来源只有四类：

1. 官方日历、事实修订和意外事件推动 State/WorldModel 更新；
2. ForecastContract 的自然时点或已版本化的材料状态触发政策推动 Forecast；
3. 行情、账户和持仓异常推动程序化 Risk 复核；
4. 主 Agent 可立即触发或增删未来触发点，并永久记录理由和版本。

组合只有一个 Scheduling owner 和一份现役 TriggerPlan。行情、事实与信息仍覆盖全部 observation assets，但在形成触发时把实际受影响资产写入 `affected_symbols`，统一投递给组合 owner；不能为每个观察品种复制 heartbeat、事件规则、Forecast cadence 或主 Agent 控制面。非 owner 品种只是 Evidence/State 的观察维度，不拥有第二个 AI、Forecast 或资本协调器。这样既保留跨资产冲击来源，又避免多个 symbol coordinator 对同一组合重复空转或产生相互竞争的调度状态。

日历外 Intelligence Event 的四项裁决必须分离：`attention_priority` 只负责有界输入排序；`immediate_review_eligible` 只负责是否唤醒 WorldModel；`directional_support_eligible` 负责能否支持因果链；Trigger 冻结的 `material_forecast_eligible` 才负责能否建立材料 Forecast 槽。来源可靠度不得乘进注意力优先级，否则最需要核验的重大低等级线索会在 AI 之前被静默删除；反过来，通过注意力门或立即复核资格也不构成事实确认、材料 Delta、Forecast 槽或资本权限。直接触发的低等级线索进入本次冻结信息面板供核验，但明确不可单独支持方向，后续不能在没有新 Evidence 时成为现役引用；同批强弱线索只能把强 Evidence 身份绑定到材料槽。不得再按 `INTELLIGENCE_INSERTED` 类型整体创建材料样本。优先级 100 的内部下游通知或明确立即触发可以即时形成自己的批次，但不得把仍在合并或冷却窗口内的普通情报一起带过时间边界；普通情报随后仍按原 TriggerPlan 重算，避免 WorldModel 输出反过来放大 AI 调用频率。

Forecast 槽的来源只有两种：合同 cadence，以及冻结触发政策产生的材料 `State/Delta`。每个槽只有一个来源、一个身份、一个 information cutoff、一次生产义务和一个终态。完成期限、Outcome、生产者行为和缺失处理都必须在结果可见前确定；每个合格槽都必须以 Forecast 或 `NO_ESTIMATE` 终结。事件槽不是临时插单，也不能只挑 AI 想交易的事件；它是一个显式的条件采样机制，永远不是定时样本的替代品。

每个 Forecast 槽必须保存规范来源集合、触发政策版本和实际 `State/Delta` 引用。触发政策只回答一项材料变化是否足以让当前组合 ForecastContract 重新估计，并冻结允许的 delta 类别、材料等级、有效时间、适用时域、与 mandate 暴露的直接交集或显式风险因子传导，以及去重窗口；不满足条件的 delta 同样保存拒绝原因。它不为每个资产复制一套槽，不解释方向，不读取仓位、WorldModel 观点或预测结果，也不根据 AI 是否想交易选择触发。材料变化发生在既有槽 information cutoff 之后时，只能形成新槽，不能修改旧槽输入。

行情检测先按资产保存原始成交和状态，再在 mandate 作用域形成市场冲击事件。组合冲击窗口内首次达到阈值立即发布；随后其他资产仅重复同一市场波动风险且没有跨越既有调度紧急等级时，仍保留原始行情，但不再发布第二个 AI 触发。只有客观紧急等级升级或窗口结束后重新达到阈值才形成新事件。该裁决只读取点时价格、冻结阈值、窗口和调度优先级，不读取 AI 输出、仓位或事后收益；因此它是同一触发政策的组合级事件形成，而不是另建一层语义去重。

Forecast 与资本回执以跨重试、投递批次和 Release 稳定的经济 `cause_id` 幂等；组合资本消费以 `(portfolio_id, cause_id)` 唯一，行为版本只作为回执内容。`trigger_batch_id` 只引用本次 Scheduling 投递事实。三者不得强制相等，也不得用一次临时 batch 或新行为版本取代经济 cause，否则重试或发版会制造第二份决策，或在 Forecast、Target、Account 已落库后无法补齐唯一回执。

触发协调器只归并同一事件形成规则下等价的材料 delta，不能归并 cadence 与事件义务，也不能把不同因果事实压成一个事件；同一组合冲击窗口内、同一风险因子且未升级的多资产阈值命中属于一个市场事件，不按 symbol 伪装成多个独立事实。材料事件即使紧邻 cadence 也立即创建独立事件槽；到达 cadence 时仍按固定锚点创建独立定时槽。额外调用是可观测成本，由触发政策评价决定是否值得，而不能先删除对照样本来节省调用。

Evaluation 分别报告仅定时和仅材料样本的到期、Forecast、`NO_ESTIMATE`、结算与 proper score；共同 Outcome 和高度重叠时域按共同事件或时间簇处理。资本层同时推进仅定时与定时加事件的前瞻逻辑账户：两者共享固定 cadence Forecast、点时市场事实、风险和执行成本，只有后者读取材料 Forecast；各自基于自己的历史持仓产生 Target 和订单，不能复用另一账户的资本动作。这样预测评价回答“是否更准确”，账户对照回答“更早重算是否覆盖新增调用和交易成本”。

TriggerCoordinator 直接产生到期槽，不依赖 WorldModel heartbeat 的相位。定时槽不强制重做 WorldModel；材料事件先更新 State 和 WorldModel，再由同一冻结触发政策决定是否产生 Forecast 槽。只有被资本控制规则选中的新 Forecast 才能改变 Alpha 资本目标；等待下一项合格资本 cause 时，旧 Forecast 仍按自身合同存在，程序化市场保护和账户风险可以独立只减险。Pipeline/协调语义变更时新 Coordinator 必须继承现有 Binding 和未终结槽，纯 Release 不重置 cohort。

这一因果边界也约束部署与持仓复核。一个组合经济 cause 一旦由任一 Capital 行为形成终态，后续 Release 或 Capital 行为版本不得把同一 cadence/material cause 当成新机会再次作用于正式模拟账户；新行为从下一个尚未消费且被自身控制规则选中的 Forecast cause 开始，旧输入只能离线重放。Heartbeat 在持仓有效时只恢复执行、对账和运行 Portfolio-independent Risk，不得因为价格、basis 或费用变化重新运行 Alpha Portfolio、改变目标金额或从旧 Forecast 新开产品；否则点时 Forecast 会被暗中改造成未登记的分钟级均值回归策略。只有冻结支持已经到期或失效时，持仓复核才可沿原链产生确定性的只减目标，且不能扩大其他有效持仓。新的合格资本 Forecast 到来时，Portfolio 才按当时完整未来成本原子比较持有、现金和合法替代表达。

同一产品出现被控制规则选中的更新 Forecast 后，Portfolio 在下一次原子决策中使用该规则指定的最新可用 Forecast 重新比较当前持有、现金和合法目标；未入选和旧 Forecast 不回写、不删除，仍按原 Outcome 独立结算。事件槽失败不能伪造方向：普通失败保留旧 Forecast 到其自然到期，只有事前冻结且与 Alpha 无关的 CRITICAL 市场或账户安全政策可以只减险。事件触发政策本身必须以“定时策略”对“定时加事件策略”的同风险、费用后前瞻账户评价响应价值，不能用多产生的 Forecast 数量或局部评分证明有资本增量；在当前无市场冲击的 Mock 范围可确定性配对，真实资本存在冲击、容量或排队差异时必须改用受控 Venue 实验。

Heartbeat 只恢复到期任务、结算、对账和遗漏的 Forecast 终态；它不自动更新 WorldModel，也不能在没有已登记槽时重复调用 Codex。到期唤醒命中尚未完成且仍在截止期内的槽时调用一次 Forecast 生产者；迟到则保存 `NO_ESTIMATE`。程序化市场保护和风险退出不等待 AI。相同任务身份只能产生一次有效运行，重试、heartbeat 和账号切换不能制造新预测样本。

触发批次只有成功、等待输入和终态失败三种处理结果。可恢复输入缺失保留同一冻结批次并按有界退避重试；Schema 或领域不变量失败只消费一次该批次、推进 heartbeat 锚点并暴露未恢复失败，不能在紧循环中重新生成同一 heartbeat。只有后续批次成功完成后才清除该异常状态，不能用进程存活或队列暂时为空冒充健康。

主 Agent 可以立即更新 WorldModel，也可以修改未来分析唤醒，但调度不是逃避实验冻结的旁路：只影响认知维护且不产生 Forecast 的唤醒记录 TriggerPlan revision 即可；新增、删除或重排会改变 Forecast 槽或样本选择的触发，必须发布新的触发政策与 producer behavior，不能与修改前 cohort 合并评价。主 Agent 因已知 Evidence 复核时必须把不可变 Evidence 身份随请求绑定，理由只解释意图、不能冒充输入事实；没有绑定 Evidence 的立即复核只能读取正常背景门已经允许的材料。未被当前冻结政策授权的立即 Forecast 仍可作为诊断运行保存，但不能进入 Portfolio。

临时 Codex 每次读取冻结的信息面板并输出结构化结果，不依赖长对话记忆。账号路由根据已配置目录的真实可用容量选择账号，目录名就是账号身份；切换不改变行为身份或投资语义。容量限制不得成为紧急分析的静默预算门，但超时、失败、账号和延迟都必须进入运行与评价事实。

主 Agent 只做三件长期工作：识别闭环当前最大的实证断点、提出一个可证伪变更、根据新结果保留或删除它。它可以调整数据覆盖、触发、模型、Prompt、预测合同、组合或风险政策，但每次 Release 必须说明改变了哪个主要假设。一个假设所需的不可分割纵向切片可以跨层修改，但必须事前说明保持不变项和无法拆分的理由；多个独立猜想不得捆绑后共同归因。主 Agent 没有独立的隐性投资账本，也不需要预建自治搜索、辩论或长期文本记忆框架。

## 7. 模块结构与依赖

目标保持模块化单体和一个权威 PostgreSQL 事实库：

```text
investment_manager/
  kernel/          # 内容身份、时间与最小通用值对象
  market/
  information/
  state/
  cognition/
  forecast/
  portfolio/
  risk/
  execution/
  governance/
  scheduling/
  decision_cycle/  # 仅编排
  entrypoints/     # CLI / worker / dashboard
  research/        # 不被生产导入
  platform/        # DB、Temporal、HTTP 等外部适配
```

允许的依赖方向是“领域纯逻辑 → 领域应用 → 外层编排与入口”。业务领域不导入 `decision_cycle`、`entrypoints` 或 `research`；Dashboard 不导入写用例；Platform 通过外层注入，不能成为业务杂物层。跨域事务由显式应用用例在同一连接上组合各领域 Repository，各 Repository 只修改自己拥有的表。

不按 `domain.py`、`utils.py`、`runtime.py` 或文件行数拆包。只有存在独立不变量和至少两个内聚能力时才建立子包。当前无消费者的抽象、禁用分支、兼容 alias、双写双读和投机性 Provider 必须删除。

## 8. 架构与实验的边界

架构只冻结本文的不变量。每个实验或 Release 另外冻结：

- mandate、允许的经济暴露、交易场所、产品和允许目标；
- Forecast 的时域、结果分布、触发和结算；
- 输入投影、生产者行为和完成期限；
- 成本、资金费用、组合政策和风险包络；
- 各问题的类型化评价计划、配对对照、动态简单基线、样本依赖和搜索历史；
- 实验候选资本资格、未来正式资本准入、最大损失、有效期、退化与停止条件。

当前 BTC/PAXG/SPY 前瞻 cohort 是这套架构的现役多资产 Forecast 与资本组件实验，不是已经证明有效的资产管理方案，也不定义永久基准、资产域或风险预算。三份经济 Forecast 在同一 AI 调用中形成并独立结算，合法产品表达由程序投影并在同一 Portfolio 中竞争；冻结参数和证据目标见 [`WORLD_COGNITION_DESIGN.md` 第 8 节](WORLD_COGNITION_DESIGN.md#8-当前证据计划)。同一 cohort 运行期间不得追改合同，但任何单资产结果都不构成其他资产研究或总组合评价的闸门。

长期主实验必须以总组合为单位独立预登记：先冻结 mandate、经济暴露、可交易 Instrument、Reference Policy、共同 Forecast、组合目标、风险包络和完整成本，再用同一输入带并行推进 Reference-only、简单程序状态和 WorldModel 条件修正的反事实账户。正式模拟账户始终只有一个 PortfolioTarget，其他路径只评价不获得资本权限。增加产品、方向或主动来源必须回答它对总组合的边际价值，并单独通过数据、产品、执行和前瞻证据验收；不因 Spot 成败机械进入 Perpetual，也不为了展示“多资产”预建通用 Sleeve、模型工厂或大量小仓位。

### 8.1 生产、研究与历史的隔离

生产运行、离线研究和历史可读性共享不可变领域事实，但不共享决策入口。生产配置只包含现役闭环所消费的政策；研究命令只负责冻结数据、形成可重复输入与检验当前经济合同，不保留另一套策略、风险、执行或旧校准配置。研究可以读取现役领域模型和匿名化历史事实，生产代码不得导入 `research`。

这条边界由三个可执行不变量共同保证，而不是目录命名约定：受管 Release 使用的生产 CLI 导入图和运行时导入闭包不得到达 `research`，仓库不得存在 `legacy` 源码包；`AppConfig` 与 Release 组件版本不得出现只被离线实验消费的策略、校准、频率、旧风险或旧执行政策；研究命令使用独立入口，但只能组合现役事实合同。托管运行 Schema 只组合现役领域所有者。历史表继续由不可改写的物理迁移保留，Alembic 不把它们解释为现役所有者或待删除对象，也不为读取历史重建旧模型、Repository、Worker 或第二套 Schema。

命令边界同样是代码边界：`investment-manager` 只注册发布、现役服务和受控运维命令，`investment-manager-research` 才注册数据冻结、回放、筛选、历史诊断和研究制品命令。两者不得通过同一个 Typer 根应用间接重合；否则每个生产子进程仍会在启动时导入整套研究依赖。

退役行为的数据库事实永久保留，但“可查询”不等于“仍运行”。Dashboard 可以通过现役只读投影展示历史行动；Outcome 可以完成迁移切流时已经登记且尚未到期的终结义务。除此之外，不保留旧 Producer、周期编排、订单入口、定时结算器、通用窗口评价或自动提案轮询。历史读取必须由拥有该审计事实的现役领域提供窄合同；仓库不存在 `legacy` 兼容包、双写或后台补算。

在线 Outcome 服务只运行当前 Release 明确启用的类型化结算器。一个旧评价器如果既不能影响现役权限，也不承担尚未到期的冻结义务，就不得因为数据库仍有旧表或 Dashboard 仍展示旧记录而继续轮询。Release、对账、风险、幂等恢复和前瞻评价属于最小生产保障；自动改代码、自动提案、通用治理评分和与现役资本无关的消融不得常驻运行。

Outcome 进程当前只承载已经登记且到期的 Forecast/Product 结算，不创建新的研究 Forecast 或产品收益投影，也不运行 Codex、posterior 或稳定性副本。世界认知 Codex 只属于 Assessment worker；它不能阻塞结算。未来实验只有在获得独立证据并完成纵向实现后，才能向 Outcome 增加一种有界任务，失败实验必须连同运行配置、入口、API 和专属测试一起移除。

## 9. 硬迁移原则

迁移只按闭环做纵向切片：先冻结目标 Release 和不可变历史，再让新路径完成 Forecast → Target → Risk → Execution → Outcome 的回放、重启和故障验收，随后原子切流并删除旧生产者、配置、入口、表写入和专属测试。

从现役单产品实验迁移到总组合只能采用以下一个依赖顺序，不能靠扩展 allowlist 横向堆功能：

1. 冻结现役 BTC cohort 与账户历史，保留其标量 Forecast 和被动 BTC 反事实仅供原实验结算；
2. 建立唯一 Mandate/可投资域与 Reference Policy，使数据、产品语义、风险包络和主基准先成为同一版本事实；Reference Policy 必须用共同情景和风险贡献证明与 Mandate 匹配，不能用资产或暴露数量门槛代替；
3. 在 Forecast 内建立联合分布和严格点时评价，先以 Reference-only、简单程序和 WorldModel 条件观点在反事实账户并行运行；
4. 用一次总组合优化替换按单 Forecast 排名填额度的分配方式，目标直接表达产品净权重；
5. 让 Risk 对同一目标校验共同情景、集中度、gross/net、流动性和保证金，让现有 Execution 从当前产品净持仓收敛到目标；
6. 完成回放、重启、成本和模拟盘前瞻验收后切换唯一 Mock 资本链，再把总账户页面投影到 Reference Policy；
7. 删除已被替代的通用 sleeve 分配、单 Spot 主基准、重复 allowlist 和只服务旧资本链的配置/代码；历史实验事实和专属评价继续只读。

这里不要求建立新的服务或账户系统。联合 Forecast 仍归 `forecast`，总组合优化仍归 `portfolio`，Reference Policy 与反事实评价仍归 `governance`，产品净持仓与订单恢复继续由现有 `execution` 权威账户承载。只有现有模型无法表达上述独立不变量时才新增数据结构，不能为迁移阶段创建永久 Adapter、双写或第二个 Portfolio 引擎。

历史 Evidence、Forecast、订单和 Outcome 保留；退役的运行机制不保留。现役实验行为必须保持到预登记停止条件或明确失败，不能因为尚无订单或尚未结算而换产品、合同、成本和风险语义。未来新产品使用独立合同、行为、Outcome 和权限，不能继承 Spot 样本。已删除的源码路径不得以兼容层、离线回放便利或页面历史读取为理由恢复。

迁移现有 Forecast 槽义务时，只能依据结果发生前已保存的 binding、派发或任务事实归属 producer behavior；无法可靠归属的旧槽保留为合同级历史并明确标记不可归因，不进入任一行为覆盖率。不得根据成功结果、当前配置或手工时间窗口反推归属。

文档不保存逐阶段完成日志、在线 PID、当前 Release 哈希或临时迁移清单；这些属于版本库、ReleaseManifest 和任务记录。权威设计只描述目标状态，避免历史实施细节永久污染架构。

## 10. 验收与否决

架构闭环可用至少满足：

- 任一资本结果都能沿唯一链追溯到点时 Evidence、Forecast、账户、授权和成交；
- 连续产生 Forecast 或明确失败，并对未交易 Forecast 同样结算；
- Forecast 覆盖率的分子与分母绑定同一 producer behavior 的槽义务；
- 权限 Outcome 不包含 Forecast 可用前收益，校准只读取此前已结算样本；
- 现金、持有、多头、空头、退出和反转由一个 Portfolio 比较产生；
- `APPROVED` Mandate 的真实购买力与外部现金流口径可计算，不以目标名称代替评价定义；
- 净资产、产品有符号名义和压力后可用流动性分别对账；含衍生品时经济现金不等于原始账本现金；
- 总账户只使用一个风险匹配的 Reference Policy 作主基准，单资产被动持有只留在对应实验归因；
- Reference 候选按 Mandate 合格性和事前择简顺序登记，不按历史收益为 Agent 选择更容易战胜的基准；
- 目标金额由总权益、共同分布、风险贡献和成本产生，不由固定单笔金额或 AI 自报信心产生；
- Risk 不能创造 Alpha，Execution 不能修改目标；无论决策来自 AI、规则、优化器或人工，都不能绕过 Portfolio、Risk、Execution 和有效授权直接改变账户；
- 独立风险动作只能减险，账户未知时先对账而不猜测下单；
- 过期判断不能续命持仓，迟到结果不能覆盖更新的资本 revision；
- 改变 Forecast 采样的 TriggerPlan 变化产生新行为身份；
- simulated 与 official Venue 复用相同成本、取整、funding、订单恢复和对账语义；
- Release 的代码、配置和前端制品内容可复核，warming 不会被展示成 ready；
- 每个可资本化 Forecast 的稳定 cause 都有唯一资本处置回执，明确现金选择与决策未形成的差异；
- 产品映射样本来自完整候选截面并消去源经济收益，部分 projection 不冒充产品选择证据；
- 评价能区分认知、预测、产品映射、组合、风险和执行各层贡献；
- 被替代路径、无消费者代码和重复裁决已经删除。

明确否决：微服务化当前单库闭环；按“AI/传统量化”或“核心/战术”建立两条资金链；新闻直达订单；多空各建一个 Agent；Spot 与 Perpetual 互相伪装；把多币种、多个产品或大量小仓位冒充多资产配置；把 BTC 被动持有当作总账户永久基准；为了产生交易降低成本或风险真实性；用月度、首日、固定次数或固定日期代替经济时点；提前建设知识图谱、向量记忆、多 Agent 辩论、自动策略工厂或默认模型组合；用调用成功、事件数量、交易次数或页面丰富度冒充盈利能力。

## 11. 组合与工程设计依据

- CPP Investments 的[2025 投资政策](https://www.cppinvestments.com/wp-content/uploads/2025/04/InvestmentStatement-InvestmentPortfolio-EN-Apr022025.pdf)在总组合层分别管理长期风险目标、因子、流动性和杠杆；其[2025 年报](https://www.cppinvestments.com/wp-content/uploads/attachments/CPP-Investments-F2025-Annual-Report-English.pdf)还明确区分市场风险目标与用于评价主动增值的可投资 Benchmark Portfolio。本设计因此让 Mandate 独立拥有绝对风险边界，让唯一 Reference Policy 只承担风险匹配的可投资中性实现和费用后反事实；当前规模不需要为这一区分再建立第二个基准对象。
- NZ Super Fund 的[2026 投资政策声明](https://nzsuperfund.nz/assets/Publications/Policies/NZSF-Statement-of-Investment-Policies-Standards-and-Procedures-2026-v2.pdf)把目标、风险偏好和 Reference Portfolio 保留为资产所有者的战略决定，把 Reference 定义为简单、低成本、可投资的总风险设定，而把主动偏离留给 Actual Portfolio；其[Derivatives Policy](https://nzsuperfund.nz/assets/Publications/Policies/Derivatives-Policy.pdf)分别报告 gross/net derivative exposure，并以现金和压力流动性管理 collateral。本设计因此不让 Agent 选择购买力目标或按历史收益挑选自己的主基准，也不把衍生品名义、现金资产和保证金压成一个权重字段。
- 欧盟对市场风险内模的[2024/1085 委托条例](https://eur-lex.europa.eu/eli/reg_del/2024/1085/oj)要求新产品在正式批准、受限额度和持续监控下引入，并单独验证代理时间序列对风险与分散化的影响。本设计借鉴的是“短历史不等于零风险，也不等于永久禁用”：新产品可在有限 Mock 包络内积累证据，但经济代理不能冒充合约自身的 funding、basis、流动性和场所风险。
- Black 与 Litterman 的[Global Portfolio Optimization](https://rpc.cfainstitute.org/research/financial-analysts-journal/1992/faj-v48-n5-28)以中性收益先验承接没有观点的资产，再按观点不确定性调整。本设计只采用“先验 + 可校准观点 + 收缩”的原则，不预设必须实现原论文模型。
- DeMiguel、Garlappi 与 Uppal 的[样本外组合比较](https://www.tse-fr.eu/sites/default/files/medias/doc/conf/fineco/papers_2010/uppal.pdf)显示复杂均值—方差规则可能因估计误差输给简单分散基线；Olivares-Nadal 与 DeMiguel 的[交易成本与稳健优化研究](https://pubsonline.informs.org/doi/10.1287/opre.2017.1699)进一步说明成本约束也能抑制估计误差。本设计因此强制简单基线、观点收缩和成本内生化，而不把优化器复杂度当作价值。
- Gârleanu 与 Pedersen 的[含交易成本动态组合研究](https://www.nber.org/papers/w15205)说明在信号持续性和交易成本并存时，应从现有持仓部分向动态目标调整。本设计因此使用成本感知的目标暴露和无交易区间，而不是每次 Forecast 清仓重建。
- Moskowitz、Ooi 与 Pedersen 的[时间序列动量研究](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum)以及跨更长历史和更多资产的[趋势跟随证据](https://www.aqr.com/Insights/Research/Journal-Article/A-Century-of-Evidence-on-Trend-Following-Investing)支持把趋势/动量作为透明候选，而不支持把月度、多资产毛收益结论直接移植到 4 小时加密合约。本设计只继承可解释假设，并要求当前目标、时域、点时数据和完整成本下的独立验证；短期反转、carry、波动和流动性同样只是竞争候选，不因“主流指标”名称获得权重。
- Binance USDⓈ-M 官方分别提供[资金费率历史](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Get-Funding-Rate-History)、[未平仓量统计](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Open-Interest-Statistics)与[主动买卖量](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Taker-BuySell-Volume)。这些是可点时验证的产品状态，不是天然 Alpha；系统只有在其增量样本外预测和费用后资本价值成立时才把它们纳入 Quant 制品，AI 只能读取冻结投影，不能从单一拥挤代理直接推断方向。
- Gu、Kelly 与 Xiu 的[机器学习实证资产定价研究](https://www.nber.org/papers/w25398)以及 Kelly 与 Xiu 的[金融机器学习综述](https://www.nber.org/papers/w31502)共同强调高维信号、非线性和样本外验证，也显示模型复杂度必须由真实预测增量而非拟合度裁决。本设计因此先冻结透明 Quant prior，再让复杂候选在同槽盲测中竞争。
- Ke、Kelly 与 Xiu 的[文本数据收益预测研究](https://www.nber.org/papers/w26186)说明文本可与市场状态共同形成可检验预测，但不证明任意语言模型叙事具有 Alpha。本设计只允许 WorldModel 通过可结算 posterior 改变 Forecast，并要求相对不读取文本的 Quant prior 证明增量。
- [FinBench](https://arxiv.org/html/2607.16229v1)把严格时间截止、基准概率和 proper score 作为金融预测评测的核心。本设计采用这些实验约束，但不把其短期基准结果视为本项目或 Codex 的盈利证据。
- 开源交易引擎 NautilusTrader 的[当前架构](https://nautilustrader.io/docs/latest/concepts/architecture/)让 backtest、sandbox 与 live 复用同一内核，并把 Risk、Execution、账户状态和 Venue reconciliation 置于明确边界。本项目借鉴的是环境等价、类型化命令和恢复语义，不照搬其消息总线、组件数量或多 Venue 平台；现有单库闭环没有被证明需要更重的基础设施。

这些外部方法只确定合理先验和否决明显错误；本项目采用何种先验、优化器、风险目标和资产集合，仍必须由自身点时回放、盲测和前瞻费用后结果决定。

最终原则：**现实先成为点时事实，认知只解释，预测必须结算，组合独占资本取舍，风险只保护生存，执行忠实收敛真实账户，结果决定任何能力是否继续存在。**
