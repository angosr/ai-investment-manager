# Investment Manager 运行观测台设计

状态：**本文定义与权威投资闭环一致的最终只读投影；实现差异按纵向切片硬迁移，不保留第二套页面语义。**

观测台不是另一套投资系统。它只把权威事实翻译为人能快速理解的中文，不推断状态、不重算投资结果，也不通过隐藏失败让系统看起来更好。

## 1. 页面必须回答的问题

加载后一屏内回答：

1. 系统和数据是否健康，当前是否允许新增风险；
2. 账户从 10,000 USDT 起点到现在真实赚亏多少，是否优于现金和风险匹配的 Reference Policy；
3. 当前世界认知是什么，依据哪些事件，哪些机制仍不确定；
4. 最近为什么选择买入、继续持有、减仓、退出或现金；
5. 当前持有什么产品风险，保护、保证金和对账是否正常；
6. Codex 账号与主机是否足以继续运行。

页面只读，不提供下单、改 Policy、切换 champion、修改触发计划或 kill switch 的按钮。操作权属于相应运行入口和治理流程。

## 2. 唯一事实来源

| 页面内容 | 唯一来源 | 页面不得做的事 |
|---|---|---|
| 健康 | 各领域 health、Release、数据新鲜度与对账事实 | 从最近一次成功行动猜测健康 |
| 权益与收益 | 已对账 `AccountSnapshot` 与冻结评价结果 | 从订单数量、K 线或旧 Outcome 拼 PnL |
| 最新世界认知 | 最新成功持久化 `WorldModel` 的直接投影 | 用附近新闻、当前行情或摘要另拼一份认知 |
| 资金决策 | 同一次闭环中相互引用的 Forecast、Target、Risk 与 Execution 事实 | 从“没有订单”反推“没有机会” |
| AI | `WORLD_UPDATE` 与 `FORECAST_ESTIMATE` 的持久化调用、输入和结果 | 用中文词表或主观质量分隐藏结果 |
| 世界事件 | Evidence/Canonical Fact/Normalized Event 的权威时间线 | 按标题相似度临时合并不同事实 |
| 当前持仓 | 最新已对账 `AccountSnapshot` | 读取旧 `PositionLifecycle` 或在前端估算仓位 |
| AI 账号 | 账号注册、容量快照、租约和 Codex run | 把快照过期等同于账号未启用 |
| 主机 | 观测台宿主机资源采样 | 宣称为各服务独立资源占用 |

所有金额、概率、成本、funding、保证金、盈亏和选择原因由后端读模型从领域事实投影；前端只负责格式化与交互。历史事实永久保留，列表使用服务端不透明复合游标分页。单页容量不是保留上限。

## 3. 固定信息结构

桌面布局保持一主列一侧栏，不增加可拖拽面板或用户自定义布局：

```text
健康条：Release / 数据 / AI / 账户对账 / 新增风险 / Kill switch
盈利曲线：净权益、费用后 PnL、回撤、现金与 Reference Policy 差异
最新世界认知：联合判断、机制链、证据引用、竞争解释、失效条件
主列：资金决策 | AI | 世界事件
侧栏：资本账户 | 当前产品持仓 | AI 账号余量 | CPU / 内存 / 磁盘
```

最新世界认知固定在盈利曲线下、主标签区上。主标签只叫“资金决策”“AI”“世界事件”；按钮之间保留清晰间距，不使用“人工智能”“市场判断”“资本复核”“组合”等不能表达对象或动作的标题。

窄屏按上述语义顺序单列折叠，侧栏不会消失。颜色只辅助状态，文字必须独立说明含义。

## 4. 内容契约

### 4.1 健康条

只展示影响继续运行或资本安全的状态：当前 Release、行情/一手事实/账户新鲜度、Trigger 与 Outcome 积压、Codex 最近成功与失败、账户对账、新增风险是否冻结、kill switch 和磁盘风险。异常展开后显示事实时间、阈值、原因与拥有领域；不显示没有行动含义的内部计数。

Trigger 健康读取当前生效 `TriggerPlan` 的 heartbeat、revision 和来源（初始默认、动态 patch 或跨 Release 继承）；静态配置只标记为初始默认。账户与调度新鲜度必须按生效计划计算，不能因主 Agent 合法调整时间点而产生假健康或假过期。

Release 就绪状态只读取当前 Release 自己的冻结制品校验和领域事实。新版本尚未形成必要账户、调度或生产者事实时显示“预热中”及缺少项；不能借用旧版本行动或单纯进程在线显示为就绪。

“服务在线”不等于“投资链有效”。Forecast 连续缺失、Outcome 逾期、账户未对账和前瞻样本不足必须分别显示，不能统称“等待”或“无机会”。

### 4.2 盈利曲线

曲线从权威账户权益序列绘制，默认显示实际净权益、现金和唯一风险匹配 Reference Policy，同时给出累计费用后 PnL、最大回撤、已实现/未实现 PnL、费用、funding、相对 Reference Policy 增值和跟踪风险。区间切换只改变查询窗口，不改变计算定义。所有指标展示其冻结口径和截至时间。

主账户不得把“相对被动持有 BTC”当作长期资产管理指标。被动 BTC 只属于现役 BTC 经济暴露 cohort 的实验反事实，放在该实验的评估详情中；总账户主视图只显示当前 mandate 冻结的 Reference Policy，名称、资产构成、目标风险和生效版本可打开。Reference Policy 尚未登记时明确显示“总组合基准尚未登记”，不能继续拿单一资产补位，也不能临时选择近期表现最好的基准。

前端不把未结仓按最新成交价自行加入收益；账户投影同时提供 mark 估值与可成交退出估值时，页面明确区分两者。没有足够前瞻证据时显示“样本不足，不能判断稳定盈利”，不能把正收益片段包装成稳定盈利。

### 4.3 最新世界认知

卡片直接展示最新成功持久化的 `WorldModel`：

- 截至时间、分析行为身份和上一认知引用；
- 当前最佳联合解释及多层传导链；
- 活跃机制的支持证据、反向证据与竞争解释；
- 每项重要事件的可点击引用及其当前影响状态；
- 程序特征验证、信息缺口、可证伪条件和失效条件。

世界认知不是 BTC 摘要，也不输出买卖命令。事件在原始事实库永久存在；当其对未来的边际影响完全消退后由认知维护流程标记过时，从当前机制中移除，过时满一天后不再作为最新认知引用。历史认知快照仍保留当时引用，页面不能用今天的过时状态回写历史。

结构合法但浅薄的认知仍如实展示并进入评价。页面不得用“验证未完成”“等待第一份通过门禁”等占位词掩盖已经产生的低质量结果；Schema 或引用失败则显示明确的调用失败，不生成伪认知正文。

### 4.4 资金决策

时间线只收录已经形成 Forecast、PortfolioTarget、RiskDecision 或 Execution 结果的真实资本决策。收起行使用人话描述最终目标状态，例如：

- “调整目标组合 · BTC 15% / 黄金暴露 20% / 现金 65%”；
- “建立 BTC 永续多头 · 目标从 0% 调整至 15% · 组合净改善 18 bps”；
- “继续持有当前组合 · 目标变化不足以覆盖转换成本”；
- “退出至现金 · 预测失效”；
- “提高现金至 65% · 风险预算收缩”；
- “目标被风险缩减 · 可用风险预算不足”。

相同原因、没有新 Forecast/Target/订单且账户状态不变的连续程序复核折叠为一条，展示起止时间与次数；这只是视图归并，不删除底层事实。保护性 heartbeat 不具有资本判断时只进入健康状态，不制造行动条目。

展开后按同一条决策链展示：触发原因 → 共同 Forecast → 当前组合与合法目标比较 → 目标权重 → Risk → Execution → 账户结果。候选表来自后端冻结事实，包含经济暴露、实现产品、当前/目标权重、边际收益、边际风险、共同尾部、适用的未来现金流、尚未发生的成本、可执行性、拒绝原因和最终选择。当前 cohort 对 BTC、PAXG 与 SPY 各保留唯一永续表达，并在同一产品上比较多头、空头与现金；Spot 只作为规范价格参考和市场证据，不显示成可执行候选、持仓或订单。总组合实验一次显示整份目标，而不是把每个产品渲染成互不相关的策略行动。未选候选不显示成第二个策略、持仓或订单。历史行动仍按当时冻结的产品域如实展示，不能被当前规则改写，也不能让历史候选混入当前持仓卡。

盈利诊断同样绑定当前 `capital_behavior_id`：新资本行为尚未形成已结算决策时，页面明确没有当前证据，不能拿最近一条旧 cohort 的 Spot/永续比较、旧成本或旧 sizing 结果填充。历史详情仍可查看其当时完整候选，这是审计记录，不是现役产品建议。

每条使用 Context Forecast 的行动都提供：

1. “查看这次 AI 看到的信息快照”：当时实际送入 Codex 的冻结输入；
2. “查看当时世界认知”：Forecast 引用的不可变认知版本及事件引用。

不能按时间邻近关系补配快照，也不能用当前世界认知回填历史行动。未来产品若支持方向反转，必须在同一行动中显示“平旧方向 → 对账 → 开新方向”的阶段；未确认平仓前不得显示反向仓位已建立。

### 4.5 AI

AI 时间线按真实调用目的区分两种记录，不再重复显示泛化的“AI 分析”标签：

- “世界认知更新”：展示联合解释、机制、引用、竞争证据和失效条件；
- “收益分布估计”：展示产品、时域、信息截止、完成时间、bucket 概率、机制贡献、Forecast/Outcome 状态和延迟。

成功记录永久可打开输入快照与输出；失败记录显示阶段、错误类别、账号、耗时及是否形成 `NO_ESTIMATE`。中文是 Prompt 与展示偏好，不是正确性门禁；后端只校验 Schema、引用、点时因果与安全边界。原始字段名或提示残渣不应进入主摘要，必要的审计 JSON 放在次级技术详情中。

预测与世界认知对照的原始计数、分层、proper score 和预登记门槛属于后端审计事实，不是资金进度条。尚无真实结果时 AI 主界面不显示空指标；有结果后只翻译为互不重复的结果数、按时输出率和相对简单基线的结论。最低样本数不得在主界面表达为下单限制或盈利保证。

### 4.6 世界事件

事件按发生时间和稳定身份分页，默认行显示发生时间、来源等级、事实摘要及是否被 AI 输入引用。对同一来源稳定文档身份，主时间线只显示截至当前最新可见的规范化修订，不能把发布切换产生的 Evidence 版本显示成多次现实事件；旧修订仍永久保留，待详情能力具备后从同一事件展开修订链。没有稳定上游身份的事件不得由前端按标题或关键词猜测合并。

“当前影响已过时”只表示它不再支撑未来判断，不表示事件消失。页面不声称展示的是“影响最大事件”，除非后端认知事实明确记录其机制贡献；排序默认按时间，不由前端计算重要性。

### 4.7 资本账户与持仓

盈利曲线承担权益、净收益和回撤展示；侧栏资金卡不重复这些指标，只显示当前可用现金、是否允许形成新订单以及尚未完成的交易。账户重放、预测样本门槛、评分术语、历史订单总数等内部诊断不得混入主状态；异常对账或风控暂停必须直接说明对资金动作的影响。研发评估保留在可审计后端事实和专项评估中，不能伪装成当前交易建议。

产品持仓卡只读最新已对账 `AccountSnapshot`，并以当前 Release 的 `execution_specs` 作为唯一可操作产品集合。当前三个经济暴露各显示一行永续产品；没有持仓时数量明确为零，不能再为同一暴露追加 Spot 行。非零持仓至少显示有符号数量、方向、entry 和当前可成交 bid/ask；mark、可成交退出估值、已实现/未实现 PnL、费用、累计 funding、经济 gross、保证金占用和强平安全边界只有在后端已有对应权威事实时才增加，不得由前端估算，也不为缺失字段堆占位诊断。账户未对账时保留最后事实但显著标注，不能显示为当前确定状态。

研发评估中的产品映射残差只展示当前配置完整映射 cohort 的前瞻样本；AI 预测行为相同但产品集合或映射版本已经退役的结果不得填充现役指标。旧结果仍可从历史行动追溯，但页面不能把跨代样本合并成看似成熟的当前证据。

“只用永续”不等于把永续伪装成现货。Spot 价格、主动流、跨场所报价继续进入 Forecast 与 basis 验证；funding、mark/index 偏离、保证金、强平、交易时段和场所风险继续进入产品 payoff、Risk 与账户归因。组合的经济 gross 仍受总权益 100% 上限约束，较低保证金占用不得被解释为额外经济杠杆。历史 Release 曾经合法的 Spot 行动保留在历史时间线中，但不进入当前可操作品种或当前持仓。

产品标识和点时数值可能很长。卡片必须允许网格/弹性子项收缩，产品标识可安全换行，数量和价格使用适合人读的展示精度并保留原值提示；任何视口宽度下都不能溢出侧栏或通过裁剪隐藏事实。

一个产品只显示一份已对账净持仓；分析来源、策略名或方向变化不制造多个影子仓位。反转恢复期间显示阶段状态，不渲染成同时存在的多头与空头。

### 4.8 AI 账号与主机

账号使用配置中的目录同名身份，例如 `.codex_affine_pb`。分别显示启用状态、最近一次可用容量、采样时间、冷却/租约、当前调用和近期失败。容量快照过期显示“已启用 / 余量快照过期”，从未探测显示“已启用 / 尚无余量快照”，不能误报为未知或未启用。路由实际选择和失败切换进入调用详情。

主机只显示观测台宿主机整体 CPU、内存、磁盘和 load average，并标明采样时间。资源采样不得成为新的监控平台。

## 5. 读模型与传输

后端只有一个只读 Dashboard 边界，按上述页面主题组装 DTO；它可以跨领域读，但不能写业务表、重算领域裁决或定义第二套状态。前端不直接读取数据库。

初始 HTTP 响应提供一致的页面快照，后续 SSE 按主题发送带稳定事件 ID 的失效通知或完整小 DTO。断线使用 `Last-Event-ID` 恢复；无法补齐时重新获取整页快照。健康、账户、账号和资源可以较快刷新，认知、决策、事件和权益只在对应事实变化时刷新。慢客户端丢弃可重建的中间刷新而不是无限积压。

分页游标绑定 `(sort_time, immutable_id)` 和过滤条件；同时间戳跨页、首页并发插入及断线恢复不得造成重复或漏项。所有查询有固定上限和超时，详情按需加载，大型原始制品不进入 SSE。

## 6. 硬迁移与删除

资本闭环迁移时，观测台与后端事实在同一纵向切片中原子迁移：

1. 先让新的资本决策 payload、账户快照与反转状态完整可读；
2. 再切换资金决策、盈利曲线和持仓读模型；
3. 同一 Release 验收后删除旧页面投影、旧 DTO、无消费者查询与测试。

不保留以下旧页面语义或兼容接口：`AnalysisCycle → AnalysisProposal → SignalCandidate → CompositionResult → FrequencyDecision → TradeIntent → PositionLifecycle → DecisionOutcome` 周期轨、从建仓订单反推方向、用 `MarketSnapshot.last` 在前端估算持仓盈亏、以及用 NO_ACTION/NO_OPPORTUNITY 制造资本行动。旧不可变事实仍留在审计库，但不混入当前资本时间线、持仓或收益口径。

## 7. 验收标准

- 最新世界认知位于盈利曲线下并包含可打开的真实事件引用；
- 每条历史 AI/资金记录都能打开其当时输入和认知，且不会被当前事实回填；
- 资金决策用中文说明当前产品合法候选、现金比较及最终动作，没有抽象占位条目；
- 连续无变化复核只在视图折叠，底层事实和分页总量不丢失；
- 权益、费用、funding、持仓、保证金和风险状态都能追溯到同一权威账户事实；
- 反转恢复不会显示两个并存方向，未对账状态不会显示成正常持仓；
- AI 账号启用与容量新鲜度分开表达，机器资源始终可见；
- 刷新、分页和 SSE 不重复、不漏项，页面自身不可改变任何投资状态；
- 源码、DTO、测试和文档中不再存在旧周期轨生产依赖。

观测台的价值是暴露真实系统，而不是让系统看起来活跃。没有认知、没有 Forecast、没有交易或没有盈利证据都必须以准确原因呈现。
